**Mike**:（D2 evaluation properties — operational definitions）
「**D2: 5 Evaluation Properties (operationally defined)**:

**(A) Bias**: $\text{Bias}(\widehat{\text{nABCD}}_X) = E[\widehat{\text{nABCD}}_X] - \text{nABCD}_X^{\text{true}}$
- True value = $W_1(F_1, F_2) / X(F_1, F_2)$ (population normalizer)
- 各 normalizer ごとに別々に true value を計算

**(B) Coverage**: 95% percentile bootstrap CI が true value を含む proportion (target: 0.95)

**(C) Cross-EM Comparability** ← **最重要**:
$$\text{CV}_{\text{EM}}(\widehat{\text{nABCD}}_X) = \frac{\text{SD across 3 EMs of mean }\widehat{\text{nABCD}}_X}{\text{Mean across 3 EMs of mean }\widehat{\text{nABCD}}_X}$$
- 同じ similarity gradient $\Delta_\sigma$ を 3 EMs で imposing したとき，empirical nABCD value が EM 間で tight か散らばるか
- 小さい CV = good comparability

**(D) Outlier Robustness**: Contaminated data ($\epsilon = 1\%, 5\%$ outliers at $\mu \pm 5\sigma$) における Bias/CI の変化量
- Robust normalizer は contamination 下でも estimate が stable

**(E) Heterogeneity Bound Interpretation**: Heterogeneity bound formula $|\bar{\tau}_1 - \bar{\tau}_2| \leq L \cdot X \cdot \text{nABCD}_X$
- 'Per-IQR L', 'per-Range L', 'per-SD L' のうち、prior elicitation での clinical accessibility (qualitative judgement)」

### [2026-05-09 11:55] Scene: Bounded W1 検討 — IQR 正規化の意味と alternatives

**INT. PEARSON SPECTER LITT — MIKE'S DESK — DAY**

*Tak は明確な direction を提示: bounded index 検討を優先する。nABCD を bounded にするより W1 を bounded にする方が素直。IQR で割る意味を問い直し、異なる EM 間で W1 を比較できるかを確認する。*

**Mike**:（構造的に）
「Tak の question を 2 つに分解する。

**Q2: 異なる EM 間で W1 比較可能か** = 不可。W1 は元の変数の単位を持つ（年 vs mmHg）。何らかの scale で割って dimensionless 化が必須。

- **W1 / Trimmed Range (Q95−Q5)**: Bounded approximation + robust の妥協

**Rachel**:（文献）
