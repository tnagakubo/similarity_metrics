## Track B Simulation Plan (Confirmed Specifications)

### D1: Normalizers (5)
$X \in \{$**IQR**, **Range**, **Q95−Q5**, **SD**, **MAD** (median-from-median, $c=1$)$\}$

### D2: Evaluation Properties (5 axes)
| Property | Definition |
|---|---|
| (A) Bias | $E[\widehat{\text{nABCD}}_X] - \text{nABCD}_X^{\text{true}}$ |
| (B) Coverage | 95% percentile bootstrap CI coverage |
| (C) **Cross-EM CV** ★ primary | SD/Mean across 3 EMs at fixed $\Delta_\sigma$ |
| (D) Outlier Robustness | Bias change with 1-5% contamination |
| (E) HB Interpretation | qualitative |

### D3: Scenarios (S1-S9 連番化, Tak confirmed 14:15)
| # | $F_1$ | $F_2$ | Type |
|---|---|---|---|
| S1 | $N(0, 1)$ | $N(0, 1)$ | Null |
| S2 | $N(0, 1)$ | $N(0.25, 1)$ | Loc 0.25σ |
| S3 | $N(0, 1)$ | $N(0.5, 1)$ | Loc 0.5σ |
| S4 | $N(0, 1)$ | $N(1.0, 1)$ | Loc 1σ |
| S5 | $N(0, 1)$ | $N(0, 4)$ | Scale 2× |
| S6 | $N(0, 1)$ | Skew-N moment-matched | Skewness |
| S7 | $\text{LogN}(0, 0.5)$ | $\text{LogN}(0.3, 0.5)$ | Combined |
| **S8** | $N(0,1)$ + 1-5% outliers $\pm 5\sigma$ | shifted | Outlier (新規) |
| **S9** | $\text{Gamma}(2, 1)$ | $\text{Gamma}(2, 1.5)$ | Asymmetric (新規) |

### D4: Cross-EM Design
- 3 EMs: Normal (Age $N(60, 15^2)$) / $t_5$ (SBP scaled at 140, 20) / LogN (Creatinine $\text{LogN}(0, 0.5)$)
- $\Delta_\sigma \in \{0.25, 0.50, 1.0\}$ (3 levels)
- Each EM: $F_2 = F_1$ shifted by $\Delta_\sigma \times$ scale parameter
- Cross-EM CV per (normalizer, $n$, $\Delta_\sigma$) = SD/Mean of empirical $\widehat{\text{nABCD}}_X$ across 3 EMs

### D5: Sample Sizes (Tak 14:15 confirmed)
$n \in \{50, 100, 200\}$ — 3 levels

### D6: Replications (Tak 14:15 confirmed)
- **10,000 reps per cell**
- **Bootstrap B = 1,000**
- True normalizer: analytic for Normal, MC $10^6$ for $t_5$/LogN/Gamma/Skew-N

### D7: Decision Criteria (4-tier)
1. **Tier 1 (Mandatory)**: Bias < 10% true at $n \geq 100$, Coverage $\in [0.88, 0.96]$ for $\Delta_\sigma \geq 0.5$
2. **Tier 2 (Primary)** ★: Cross-EM CV (smaller better, averaged at $\Delta_\sigma = 0.5$, $n = 100$)
3. **Tier 3 (Secondary)**: Outlier robustness (Bias change with 5% contamination)
4. **Tier 4 (Tertiary)**: Heterogeneity bound interpretability (qualitative)

Final: Pareto-optimal across Tier 1-3, Tier 4 で tie break

- Figure: Bias/Coverage panel + Cross-EM CV panel
