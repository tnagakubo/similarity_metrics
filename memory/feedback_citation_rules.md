論文の引用は次の 7 規則で置く（similarity-metric `DECISIONS.md` D-20261114-2）。

1. 引用はその出典が支える**節の直後**。自前の結果・導出を含む文の文末に置かない
2. 自前の結果・導出・simulation には引用を付けない（節・図表で指す）
3. 一つの事実に一つの出典。重ね引用、同じ文・隣接文での同一出典の繰り返しをしない
4. 引用符つきの語句にはその場で出典
5. 原典を読んで verbatim で照合できたものだけ。未読の key は読了済みの出典に替えるか外す
6. 試験・データ・手法の出典は初出に一度
7. 初等的な事実には付けない

**Why:** Tak（2026-11-14）「引用位置は学術論文として適切な位置に決めろ。過剰な引用もよくないはずだ。引用のルールを再確認しておけ。」`andrews2000` が自前の simulation 結果の文末に、`villani2009` が同じ小節に 4 回付いていた。

**How to apply:** 引用を足す・動かす前にこの 7 行を当てる。`/cite-check` の PARTIAL / NV は「文を直す」より先に「その引用は要るか」を問う。関連: [[feedback-evidence-over-inference]]
