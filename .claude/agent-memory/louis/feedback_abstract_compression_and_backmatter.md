Terminal pass (abstract / abbreviations / Data availability / SI) is where this team's restrictors silently fall off.

- Abstract compression dropped "depends on X alone" from Proposition 1, the criterion behind "needed fewer patients" (selection AUC 0.9), and turned a body disclaimer (Komiyama RV = "scope observation rather than a criticism", binary proportions) into a criticism; "representative-value distances were blind" folded our RV2/RV3 into "a published strategy".
- Secondary sources mis-attributed: Song 2025 authors are Peking Univ + industry (not NMPA); their clustering cites the same Li et al. volume as Komiyama, distance = EM-endpoint correlation.
- Data availability named only GUSTO-I while Supplement C also uses IST-3 and IST-1.
- Supplement B existed only as an internal lab .md (v2 / IST-3 residue, star ratings); a second file also self-titled "Supplement B"; Supplement A kept "nABCD".

**Why:** each edit round verifies numbers (logs ALL PASS) but not assumption lists, source provenance, or file-level SI reality.
**How to apply:** on any abstract/back-matter review: diff every abstract sentence against the Proposition statement and the body's own caveats; recount words after fixes; grep supplements' titles and datasets vs SI list and Data availability.
