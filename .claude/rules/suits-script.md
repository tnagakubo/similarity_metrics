# SUITS.md rules（脚本ファイルを触るときだけ読み込まれる）

- 新シーンは `## 🎬 Live Script` 直下（TOP）に追加。逆時系列
- 見出し: `### [YYYY-MM-DD HH:MM] Scene: {title}` → `**INT. PEARSON SPECTER LITT - {LOCATION} - DAY/NIGHT**` → *stage direction*
- 発言は `**Name**:（emotion）` の次行に `「...」`。ファーストネームのみ。性別・口調は CLAUDE.md Rule 3 / 3.8
- 「全部記録したわ」だけの Donna は禁止。観察・助言・皮肉を含める
- `## Current Status` ブロックの Phase 行は `projects/{project}/LAB_STATUS.md` と一致させる
- 1000 行超で `/archive`。900 行で準備
