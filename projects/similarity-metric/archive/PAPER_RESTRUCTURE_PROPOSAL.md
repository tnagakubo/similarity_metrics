## 2. Methods（詳細）

### §2.1 The pooling-partner selection problem 〔新規・短い〕

**本論文が扱う問題を明示する**（目的: 併合相手の選択）:

> ある地域が pooling 戦略を取るとき、どの地域を併合相手として選ぶか。

現行 §2 冒頭（式 1: τ̄_r = ∫τ dF_r）はここに吸収し、**選択の判断対象が anchor の異質性上界であること**を明記する。

そのうえで**隣接する別問題との境界を1段落で引く**（対等な2設定として並べるのではない）:

- **本論文の問題** — anchor が併合相手を選ぶ。保証すべきは anchor 自身の上界
- **隣接問題** — planning stage で pooled region を形成し**全メンバーが共有推定値を報告**する（E17 の pooled regions 定義、小宮山 Ch.4 の設定）。こちらは相互距離の条件が追加で必要（§2.7）

### §2.3 Per-EM W₁ と heterogeneity bound 〔S1 修正の置き場所〕

Prop 1（|Δτ̄| ≤ L·W₁）は現行のまま。**¶146 の以下を差し替える**:

❌ 現行「The alternative measures discussed in Section 2.1 similarly lack any analogous property.\cite{gibbs2002}」
❌ 現行「W₂ ... does not possess a Lipschitz dual representation and therefore cannot provide an analogous bound」

✅ 差し替え後の骨子（**非入れ子**として書く）:
- KR 双対より **L·W₁ は Lipschitz CATE クラス上で sharp**（達成される）
- 部分積分より KS も上界を持つ: **|Δτ̄| ≤ D_KS · TV(τ)**、これは **BV/階段 CATE クラス上で sharp**
- **どちらも妥当。どちらが tight かは、分布が食い違う場所で CATE が動くかで決まる**（検証済: 非飽和 τ では全セルで W₁ 上界が tight、飽和 τ の rare-extremes d=100 でのみ KS が tight）
- W₂ は W₁ ≤ W₂ より妥当だが緩い上界を与える（「与えられない」は誤り）
- **決め手は較正定数**: L = per-unit interaction slope（IPD meta-regression が報告する量、riley2010/fisher2017 で既引用）／TV(τ) = CATE の全振幅（報告されず、新規薬では未知）
- `\cite{gibbs2002}` は訂正後の記述に再利用

> **効果**: 誤った uniqueness 主張が、双対性に基づく精密な議論に変わる。査読者が同じ計算をして突いてくる経路を塞ぐ。

### §2.6 Operability: the null floor 〔新規・重要、独立節を維持 — Tak 判断 2026-08-15〕

⚠ **判断③決定（Tak 2026-08-15）: 独立節として維持し、§2.5 → §2.6 を一本の較正の弧として書く。** 根拠: ①Q_operability は論文が答える3つの最上位の問いの1つ ②§4.2 は Application の独立節であり対応を保つべき ③abstract が診断を応用の要点として名指ししている ④**決定的には、独立性こそが §4.2 を「手法のつまずき」ではなく「診断の仕事」として読ませる**。弧の枠組みが「単独節＝解像度の問題の告白」と読まれる唯一実在のリスクを消す。**§2.6 を唐突に始めるな — τ_clin から入れ。** 長さは制約でない（`.tex` 約 9,830 words、Methods 約 2,111）。

**中身**: Ŵ₁ は非負なので、F₁ = F₂ でも有限標本では正の値を返す。その**帰無時の標本分布**（bias ではなく分布）が推定量の解像度を決める。閾値則が機能する必要条件:

> **τ_clin > 帰無床の上側パーセンタイル**（当該 n・当該形状で）

**診断法**: 一方の地域の経験分布から実サイズで2標本を再抽出し、Ŵ₁ の帰無分布を作る。実行コスト数秒。

⚠️ **これは §3 の「n ≥ 100 推奨」の言い換えではない**（査読者はそう読む恐れがあるので本文で明示的に否定する）:
- n ≥ 100 は **bias/coverage** から出た数字で、推定の質の基準
- operability は **帰無床と τ_clin の比較**で、n だけでなく**臨床要件の厳しさと EM の形状**に依存する
- **証拠**: GUSTO は n ≈ 2,900 で n≥100 を遥かに満たすが、**age では operability に失敗する**（§4.2）。両者が一致しないことがこの節を独立させる根拠

**既存証拠との接続**: §3 の S1（帰無 bias 2.46 → 1.26）と Part 1B の operable range（厳しい τ_clin は n≤100 で決定不能、誤りの方向は棄権）は、この節の一般命題の2つの実例になる。現行では散在した caveat、再構築後は**方法論の構成要素**。

**RV1 と SMD の Spearman = 1.0000（両 EM、順位完全一致）**、Pearson 0.9999 / 0.9995。

#### 結果 3 — ✅ モーメントを足すと選択が変わる（が、良くなる保証はない）

RV2（+SD）と RV3（+skew）だけが consensus から外れる。SBP での W₁ 順位との Spearman は **RV2 0.643 / RV3 0.536** と大きく劣化（SMD/RV1 は 0.954）。

→ simulation の所見「**モーメントを足すのは無料ではない**」（Set 1 で RV3 は RV2 より悪い）と整合。**応用と simulation を組み合わせて初めて『RV2/RV3 の逸脱は情報でなくノイズの可能性が高い』と言える** — これが両者を並べる価値。

#### 結果 4 — ✅ 手続きは大きく分岐し、それを分けているのは直径条件（P5 も確認）

*この結果は従来別々に書かれていた2つ（手続き比較と旧 §4.5 の pool 水準検証）を担う。両者が同じ場所に属するのは、**手続き間の分岐がそのまま直径条件だから** — 対比較は anchor estimand に、complete-linkage cut は共有 region の読みに答え、9 と 2 の差はその追加条件の値段。**所見＋caveat ではなく一本の論証として読ませる。***

W₁ 距離行列に3手続きを適用（16 地域）:

| EM | 対比較 τ screen | complete linkage τ cut | silhouette k̂ |
|---|---|---|---|
| age | **9 地域** | **2 地域**（R5, R6） | k̂=3 → 10 地域 |
| SBP | **11 地域** | **2 地域**（R2, R16） | k̂=2 → 2 地域 |

- **P5 確認**: cut-pool ⊆ pairwise pool が両 EM で成立（理論の帰結どおり）
**pool 水準の検証 — §2.7 の worked example をここに集約〔Tak 判断 2026-08-15〕**

まず**手法が主張していること**から始める: anchor→partner は age・SBP とも**全て τ 以内**であり、R8 自身の異質性上界は成立する。**目的（併合相手選択）に対して pool は妥当で、約束されたものは何一つ破られていない。** これは P2（凸性）が保証する当のものであり、全ペア制約ではなく対比較 screening が手続きである理由。

直径条件が適用されるのは**別の読み**（pool を共有 pooled region と見なし、anchor だけでなく全メンバーが上界を担う）**のみ**。その読みでの直径は、どの pool を指すかに依存する:

| 対象 pool | age（τ=1.0） | SBP（τ=5.0） |
|---|---|---|
| R8 + **joint** eligible 6地域（§4.4） | 1.0595 — **5.95% 超過**、15相互ペア中1本（R1–R6） | 4.7243 — 合格 |
| R8 + 各 EM **自身**の pairwise 採択集合 | 9地域 → 1.1093、**10.9% 超過** | 11地域 → 8.9362、**78.7% 超過** |
| R8 + 高さ τ で complete linkage cut | 2地域 → 0.9121、合格 | 2地域 → 4.2823、合格 |

→ **所見は超過ではなく、直径を強制する費用のほう。** 共有 region 条件を課すと併合可能な相手は age 9→2（**78% 減**）、SBP 11→2（**82% 減**）。これが追加的保守性の値段であり、anchor estimand を scope とする実務上の理由。
→ **欠陥の告白ではなく scope の明確化として書く**: 「本手法は anchor の異質性上界を保証する。pool を全メンバーで共有する意図があるなら、相互距離の条件が追加で必要であり、この例では age で1ペアがそれを破る」。
→ 各一文で足りる細部が2つ。**(i)** 超過ペア R1–R6 の **R6 は §4.4 が age の境界地域として名指しする当の地域** — 無関係な caveat 2件より収束として述べるほうが強い。**(ii)** SBP では joint pool の直径を決めているのが相互ペアではなく anchor→partner（4.7243）なので、**この EM では anchor 自身が pool の端点であり、共有 region 読み替えの追加コストはゼロ。**
→ 伏せる危険: 査読者が同じ計算をして「あなたの理論が指摘した罠に、あなたの応用が落ちている」と書く。**先に書けば scope の明晰さの証明になる。**

⚠ **執筆時の注意 — 上表には3つの直径があり、それぞれ別の量。** ラベルなしで2つを同じ文に置くな（age の 1.0595 と 1.1093 が近接すれば読者は片方を誤植と読む）。**必ず pool を明示すること。** 関連: age の cut pool 直径 0.9121 は age の anchor→partner 最大と数値が一致するが偶然であり、散文中では離すこと。
- **しかし規模の差が大きい**（9 対 2、11 対 2）= 共有 region を意図するなら**併合できる相手は激減する**。これは実務的に重要な数字

#### 結果 5 — ρ ヒューリスティックの実データ挙動

ρ = W₁/(KS·σ_EM) を全ペアで算出（CSV に格納）。KS が W₁ と持つ順位相関は age 0.964・SBP 0.957 = simulation の「ρ/ρ_trans ≲ 1 なら KS が並ぶ」領域に GUSTO が位置することと整合。**KS が並ぶことは予測どおりであり、W₁ の敗北ではない。**

⚠ **ρ の画定を必須の一文で書く（判断⑤、Tak 2026-08-15 — 格上げしない）。** ρ は**本例で手法が一致した理由を事後に説明するものであり、W₁ を使うか否かを事前に決める選別規則ではない**。分子に W₁ があるため ρ の算出は W₁ の算出を前提とし、言えるのは「KS で足りたか」だけ。閾値（≲1 / ≳1.7）も適合させた当のスタディを retrodict するもので held-out 検証がない。**書かなければ読者は ρ を提案手法と受け取る。**

#### §4.5 の位置づけ（考察の骨格）

> simulation は**失敗様式の存在**と**いつ発現するか**を示す。応用は**この特定のデータではそれが発現しない**ことを示す。両者を並べて初めて言えるのは:
> ① 位置優位のデータでは既存手法で足りる — **W₁ は害を与えない**
> ② 発現する構成は現実的（混合分布・希少極値は臨床で普通）であり、**事前には自分がどちらの世界にいるか分からない**
> ③ ゆえに W₁ を使う理由は「常に違う答えを出すから」ではなく、**「答えが変わる世界でも壊れず、かつ臨床較正を持つ唯一の選択肢だから」**

⚠ **これは現行 abstract/Discussion の含意より控えめ**。現行は W₁ の優位を実務的差として示唆しているが、GUSTO はそれを支持しない。**この controlled な言い方に揃える必要がある。**
