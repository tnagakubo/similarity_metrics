要旨

主要評価変数の群間比較は、実務上ほぼ例外なく位置（平均あるいは中央値）の 比較に帰着している。しかし治療効果は位置だけに現れるとは限らない。分散を 縮小する治療、一部の患者のみが強く反応する治療、天井効果のある評価尺度では、 分布は位置以外の方向に動く。

本稿では Neyman の smooth test を 2 標本問題に適用し、群間差を直交する 解釈可能な成分（第 1 成分 = 位置、第 2 成分 = 尺度、第 3 成分 = 歪度、 第 4 成分 = 裾）へ分解する枠組みを実装・評価した。要点は次の 4 つである。

  1. 第 1 成分 Z1Z_1 は Wilcoxon 順位和統計量の標準化値と代数的に厳密一致する （同順位がある場合も含む）。すなわち smooth test は Wilcoxon 検定を第 1 成分 として内包し、そこに解釈可能な高次方向を追加した検定である。
  2. 有限母集団共分散を用いることで、同順位・離散値があっても成分は厳密に 直交し、Wk=Z12+…+Zk2W_k = Z_1^2 + \dots + Z_k^2 という入れ子構造が正確に成立する。
  3. 治療がばらつきや形状を変える状況では、t 検定・Wilcoxon 検定の検出力は 名義水準 5% から動かない一方、smooth test は 1 群 50 例で 70% 超の検出力を 示した。代償として、純粋な位置シフトでは相対的に検出力が約 10〜25% 低下する。
  4. GUSTO-I の実データで、標準化平均差 −0.02-0.02、Wilcoxon p=0.89p = 0.89 の 2 群間に smooth test が p<0.001p < 0.001 の差（尺度・歪度成分）を検出した。

本稿の数値はすべて本リポジトリのスクリプトで再現できる。文献情報はオフライン 環境で作成したため、投稿前に原典で確認されたい。

1 背景

2 標本問題に対する標準的な検定は、暗黙のうちに対立仮説を限定している。

検定 実質的な対立仮説 位置以外の差への感度
t 検定 平均の差 なし
Wilcoxon 順位和検定 確率優越（P(Y>X)≠1/2P(Y>X) \ne 1/2） ほぼなし
Kolmogorov–Smirnov 分布の差（一般） 弱い
Anderson–Darling 分布の差（裾重み付き） 中程度

臨床試験で位置以外の差が生じる典型的な状況は次のとおりである。

  • 反応者部分集団: 一部の患者のみが強く反応し、残りは不変。平均は動くが 分布は二峰性・歪んだ形になる。
  • 安定化作用: 血糖変動、血圧変動、疼痛スコアなどを「ばらつかせない」ことが 治療目的である場合。平均差は小さくても分散差が大きい。
  • 天井・床効果のある評価尺度: QOL スコア、機能評価尺度。
  • 地域間の患者背景分布: MRCT において、平均は揃っていても分散や歪度が 異なる地域がある（第 4 節）。

Kolmogorov–Smirnov 検定や Anderson–Darling 検定は omnibus ではあるが、 有意になった理由を説明しない。規制当局への説明が必要な臨床試験では、 「分布が異なる」だけでは不十分で、「どの方向に異なるのか」が要る。 Neyman の smooth test はまさにこの分解を与える。

2 方法

2.1 定義

対照群 X1,…,Xm∼FX_1,\dots,X_m \sim F、試験群 Y1,…,Yn∼GY_1,\dots,Y_n \sim G、N=m+nN = m+n とする。 帰無仮説は H0:F=GH_0: F = G である。

[0,1][0,1] 上の正規直交 Legendre 多項式 b1,…,bdb_1,\dots,b_d （∫01bj=0\int_0^1 b_j = 0, ∫01bjbl=δjl\int_0^1 b_j b_l = \delta_{jl}）を用いる。低次の 4 つは

b1(u)=3(2u−1),b2(u)=5(6u2−6u+1),b3(u)=7(20u3−30u2+12u−1),b4(u)=3(70u4−140u3+90u2−20u+1), \begin{aligned} b_1(u) &= \sqrt{3}\,(2u-1), \\ b_2(u) &= \sqrt{5}\,(6u^2-6u+1), \\ b_3(u) &= \sqrt{7}\,(20u^3-30u^2+12u-1), \\ b_4(u) &= 3\,(70u^4-140u^3+90u^2-20u+1), \end{aligned}

であり、それぞれ位置・尺度・歪度・尖度（裾）方向に対応する。

併合標本の中間順位 RiR_i から ui=Ri/(N+1)u_i = R_i/(N+1) とし、スコア行列 Aij=bj(ui)A_{ij} = b_j(u_i)（N×dN \times d）を作る。試験群の添字集合を TT として 成分和を Sj=∑i∈TAijS_j = \sum_{i \in T} A_{ij} と定義する。

2.2 同順位に対する厳密な帰無モーメント

無作為化（交換可能性）の帰無仮説の下で TT は NN 個から nn 個を非復元抽出した 単純無作為標本であるから、同順位の有無によらず厳密に

E[Sj]=na‾j,Cov[Sj,Sl]=n(N−n)N−1Cjl,Cjl=1N∑i=1N(Aij−a‾j)(Ail−a‾l) \mathrm{E}[S_j] = n\,\bar a_j, \qquad \mathrm{Cov}[S_j, S_l] = \frac{n(N-n)}{N-1}\, C_{jl}, \qquad C_{jl} = \frac{1}{N}\sum_{i=1}^{N}(A_{ij}-\bar a_j)(A_{il}-\bar a_l)

が成り立つ。Σ=n(N−n)N−1C\Sigma = \frac{n(N-n)}{N-1}C の Cholesky 分解 Σ=LL⊤\Sigma = LL^{\top} を用いて

Z=L−1(S−E[S]),Wk=∑j=1kZj2 Z = L^{-1}(S - \mathrm{E}[S]), \qquad W_k = \sum_{j=1}^{k} Z_j^2

とすれば、WkW_k は先頭 kk 成分の二次形式 (S−ES)1:k⊤Σ1:k,1:k−1(S−ES)1:k(S-\mathrm{E}S)_{1:k}^{\top}\Sigma_{1:k,1:k}^{-1}(S-\mathrm{E}S)_{1:k} と厳密に 一致し、H0H_0 の下で漸近的に χk2\chi^2_k に従う。

連続データの理想的な場合には C≈IC \approx I だが、血圧や脈拍のように同一値が 大量に出る変数では CC の非対角成分が無視できない。理想化した分散 nm/Nnm/N を用いる実装は、この場合に成分が直交せず WkW_k の分布が歪む。 上式はこれを厳密に回避する。

b1b_1 は順位の 1 次関数なので、Z1Z_1 は同順位補正込みの Wilcoxon 順位和統計量の 標準化値と厳密に一致する。本実装で数値的に確認した（下記）。

この関係は実務上重要である。smooth test を採用しても Wilcoxon 検定の結果は 捨てられない——それは第 1 成分としてそのまま報告できる。

2.4 成分数 dd と kk の選択

dd を大きくすると検出できる対立仮説は広がるが、検出力は薄まる。Ledwina の Schwarz 型規則

S=arg⁡max1≤k≤d{Wk−klog⁡N} S = \arg\max_{1 \le k \le d}\ \{ W_k - k\log N \}

によりデータから kk を選び、WSW_S を検定統計量とする方法（以下 data-driven）を 実装した。

2.5 較正

data-driven 統計量の帰無分布は χ12\chi^2_1 に収束するが、収束は遅い。 臨床試験の実サンプルサイズでは漸近近似はアンダーカバーになる。

data-driven 統計量の帰無分布（20,000 回）。 chi2_1 近似は名義 5% に対して過大な棄却率を与える。
1群あたり例数 厳密95%点 (W_S) chi2_1 の95%点 chi2_1 を使った場合の実際の第一種の過誤
50 5.37 3.84 0.083

連続データで同順位がなければ、順位統計量の帰無分布は (m,n,d)(m, n, d) のみに依存する （分布非依存）。したがって厳密臨界値は試験ごとに事前に表化でき、計算コストは 解析時にはかからない。同順位がある場合は併合標本上の並べ替えで較正する （calibrate = "permutation"）。

推奨: 同順位が無視できるなら事前表化した厳密臨界値、同順位があるなら 並べ替え較正。χ2\chi^2 近似は固定 kk の場合にのみ使う。

3 シミュレーション

1 群 50 / 100 / 200 例、有意水準 5%、各セル 5,000 反復 （Monte-Carlo 標準誤差 ≤\le 0.7 パーセントポイント）。 順位検定はすべて厳密な分布非依存臨界値を用いた。

3.1 第一種の過誤

正規分布の帰無仮説下での棄却率。 対数正規の帰無仮説でも順位検定は同一の値を与える （単調変換で順位が不変＝分布非依存の直接的な確認）。
検定 n=50 n=100 n=200
t-test (Welch) 0.0488 0.0514 0.0496
Wilcoxon 0.0460 0.0484 0.0510
Kolmogorov-Smirnov 0.0354 0.0348 0.0384
Anderson-Darling 0.0462 0.0502 0.0476
Smooth k=2 0.0508 0.0548 0.0456
Smooth k=4 0.0542 0.0540 0.0502
Smooth data-driven (BIC) 0.0494 0.0530 0.0412

Kolmogorov–Smirnov 検定のみ保守的（3.5% 程度）である。これは統計量の離散性に よるもので、実装の問題ではない。t 検定は対数正規の帰無仮説下でわずかに 保守的になる（0.0412、n=50）。

3.2 検出力

読み取れる構造は 3 つある。

(a) 位置シフトでは smooth test は劣る（想定どおり）。 正規・位置シフト 0.35 SD、1 群 50 例で t 検定 0.406、 Wilcoxon 0.387 に対し data-driven smooth は 0.277。 このとき BIC が選ぶ成分数の平均は 1.03 であり、ほぼ常に k=1k=1（すなわち Wilcoxon 統計量そのもの）が選ばれている。 検出力差は統計量の違いではなく、選択を許したことによる帰無分布の 裾の厚み——臨界値が 3.84 ではなく 5.37 になること——から生じている。 これが data-driven 化の正味の代償である。n=200 では差は 0.023 まで縮む。

(b) 尺度・形状差では他の検定に検出力がない。 SD 1.0 対 1.6（平均・中央値は 同一）で 1 群 50 例のとき、t 検定 0.048、 Wilcoxon 0.049 と名義水準のまま動かない。Anderson–Darling が 0.358、 smooth (k=2k=2) は 0.700。 平均を 0.2 SD 動かしつつ SD を 0.6 に縮める「安定化」シナリオでも同様で、 1 群 50 例で t 検定 0.227 に対し smooth (k=2k=2) 0.822。

(c) 反応者部分集団は平均で十分に捉えられる。 25% の患者が 1.6 SD 反応する シナリオでは、平均差 0.4 SD が生じるため t 検定が最良 （1 群 50 例で 0.420）。 smooth test はやや劣る。部分集団の存在そのものを検出したいなら混合分布の モデリングが要るのであって、omnibus 検定はその代替にならない。

3.3 固定 kk と data-driven の使い分け

高次の形状差（歪度のみが異なり平均・SD が一致するシナリオ）では、 k=4k=4 固定が data-driven を大きく上回る （1 群 200 例で 0.804 対 0.489）。 BIC の罰則 log⁡N\log N は高次成分の採用に厳しく、Z3,Z4Z_3, Z_4 が中程度の大きさの 場合に採り損ねるためである。

  • 懸念がばらつきの差に集中しているなら k=2k=2 を事前規定する。
  • 形状差一般が懸念なら k=4k=4 を事前規定する。
  • 事前に方向を絞れないなら data-driven（d=4d=4）を使う。

5 臨床試験での実装に関する提言

5.1 何を検定しているのかを明示する

smooth test の帰無仮説は F=GF = G であり、これは ICH E9(R1) のいう estimand とは 直接対応しない。「治療群と対照群の分布が等しい」という帰無仮説の棄却は、 治療が有益であることを意味しない——分散が増えただけでも棄却される。 したがって次の役割分担を推奨する。

  1. 主要解析は従来どおり（推定量＋信頼区間、位置に基づく検定）。estimand に 対応した推定値を主張の根拠とする。
  2. smooth test は事前規定された副次的／補足解析として、 「治療が分布のどの側面を変えたか」を記述する目的で用いる。
  3. 成分 Z1,…,Z4Z_1,\dots,Z_4 を Holm 調整つきで報告し、 有意になった成分に対応する記述統計（群別の SD、歪度、分位点）を併記する。

5.2 事前規定すべき項目

  • dd（最大成分数）: 4 を既定とする。d>6d > 6 は検出力上の利点がほとんどない。
  • kk の決め方: 固定（k=2k=2 または k=4k=4）か data-driven（BIC）か。 第 3 節の使い分けに従う。
  • 較正方法: 並べ替え（反復数を明記）か事前表化した厳密臨界値か。
  • 打ち切り・欠測の扱い。smooth test は完全観測の連続変数を前提とする。

5.3 成分の報告様式（例）

主要評価変数について、Neyman smooth test（Legendre 順位スコア、d=4d=4、 並べ替え較正 10,000 回）を事前規定の副次解析として実施した。全体の p=0.003p = 0.003 であり、成分分解では位置成分 Z1=0.41Z_1 = 0.41（Holm 調整 p=1.00p = 1.00）、 尺度成分 Z2=−3.12Z_2 = -3.12（Holm 調整 p=0.005p = 0.005）であった。治療群の標準偏差は 対照群の 0.71 倍であり、平均値に差は認められなかった。

6 限界

  • 完全観測の連続変数に限定される。 打ち切りのある生存時間には適用できない。 打ち切り対応の smooth goodness-of-fit（Peña 型）は別途の定式化が要る。
  • 順位に基づくため、効果量そのものを与えない。 検定であって推定ではない。 分布差の大きさを定量したい場合は Wasserstein 距離などと併用する。
  • 第 4 節の例示は探索的に選ばれた組合せである。 600 通りから 選んだ 1 例であり、そこでの pp 値は選択バイアスを含む。方法の挙動を示す 例示であって、地域差に関する確証的知見ではない。
  • 多重性。 成分ごとの pp 値を報告する場合、全体の検定と成分の検定の関係を 事前に定める必要がある（本稿では閉検定手順を採らず、全体 pp を主とし成分は Holm 調整つきの記述と位置づけた）。
  • シミュレーションは等例数配分のみを扱った。極端な不均等配分（例 3:1）は 未評価である。

7 次に進めるとよい方向

  1. 打ち切り対応: 生存時間主要評価変数への拡張。非比例ハザードの検出を 低次の直交成分として定式化できる。
  2. 共変量調整: 層別／回帰調整した残差に対する smooth test、あるいは 条件付き分布 F(y∣x)F(y \mid x) の比較への拡張。
  3. 推定への接続: 成分 ZjZ_j に対応する分布汎関数の推定と信頼区間。 検定から推定へ移せば ICH E9(R1) の枠組みに乗せやすくなる。
  4. MRCT への応用: 地域間の効果修飾因子分布の比較に成分分解を用い、 Wasserstein 距離による定量と組み合わせる（第 4.2 節の方向）。
