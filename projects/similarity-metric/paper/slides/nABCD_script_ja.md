## スライド 4: MRCT と ICH E17
（想定時間: 1.5分）

まず背景です。

MRCT は国際的な医薬品開発の標準パラダイムであり、ICH E17 ガイドラインが2017年にその設計原則を規定しました。各規制当局は地域部分集団における治療効果の一貫性を求めていますが、個々の地域のサンプルサイズだけでは一貫性の評価が困難なことが多い。そこで ICH E17 は effect modifier の分布が類似した地域同士をプーリングするアプローチを記述しています。

ところが、ここに大きなギャップがあります。ガイドラインは「類似した分布の地域をプーリングせよ」とは言っているものの、"similar enough" をどう判断するかについて、定量的な方法論を提供していません。つまり、方針はあるがツールがない状態です。本研究はこのギャップを埋めることを目指しています。

---

## スライド 5: Effect Modifier とは
（想定時間: 1分）

ここで effect modifier の概念を確認します。

Effect modifier とは、治療効果がサブグループ間で異なる原因となる患者背景因子です。例えば年齢が effect modifier であれば、若年患者の方が治療反応が良い、という状況が生じます。

重要なのは、薬が個人レベルでは同一に作用していても、地域間で患者構成が異なれば、地域の平均治療効果は異なりうるという点です。スライドの式が示しているのは、地域の平均治療効果は CATE と effect modifier 分布の積分で決まるということです。つまり分布が違えば、同じ薬でも地域平均が変わる。だからこそ effect modifier 分布の類似性が、プーリングの妥当性の鍵になるわけです。

---

## スライド 6: 既存手法の限界
（想定時間: 1分）

では、現在使われている指標は何が問題なのか。

皆さんが最もよくご存じの SMD、つまり標準化平均差は、解釈が容易でスケールフリーという優れた性質を持っています。しかし、SMD は位置、つまり平均の差しか捉えません。分散や形状の差は完全に無視されます。

スライド下部の例を見てください。平均がどちらも50で、標準偏差が5と15の2つの正規分布を比べると、SMD はゼロです。分散が3倍異なっているにもかかわらずです。KS 統計量は分布全体を比較できますが、臨床的に何を意味するかが不明確で、治療効果との理論的連結もありません。KL ダイバージェンスは非対称で、小サンプルでは不安定です。

つまり、位置以外の分布特徴を捉え、臨床的に解釈可能で、かつ治療効果と理論的に連結できる指標が必要です。この3つの要件を同時に満たすものがこれまでなかったのです。

## スライド 8: nABCD の定義
（想定時間: 2分）

ここからが本研究の提案です。

nABCD の基盤は Wasserstein-1 距離、いわゆる Earth Mover's Distance です。これは幾何学的には、2つの累積分布関数の間の総面積を表しています。CDFの間を塗りつぶしたときの面積が、そのまま2つの分布の距離になる。直感的にわかりやすい距離です。

nABCD は、この Wasserstein-1 距離をプールされた分布の IQR の2倍で割ったものです。この正規化により、測定単位に依存しないスケールフリーな指標になります。分母に IQR を使う理由は、IQR が中央50%の散らばりとして直感的に理解しやすいからです。係数2は、1-IQR 分の位置シフトで nABCD が0.5になるように較正するためのものです。

この定義により、異なるスケールの effect modifier を同じ土俵で比較できるようになります。年齢（年単位）と NIHSS スコア（点数単位）を、同じ nABCD の尺度で並べて議論できるわけです。

---

## スライド 9: nABCD の3つの要件充足
（想定時間: 1.5分）

ここまでの話をまとめると、nABCD は先ほど挙げた3つの要件をすべて満たしています。

第一に、Wasserstein-1 距離は位置だけでなく、分散・歪度・形状の差にすべて反応します。SMD が検出できない分布差を捕捉できます。

第二に、IQR 正規化によりスケールフリーな臨床的解釈が可能です。参照ベンチマークを使えば、L の情報がなくても初期評価ができます。

そして第三に、ここが最も重要ですが、Kantorovich-Rubinstein の双対性定理により、治療効果の異質性に対する理論的な上界を提供できます。この性質は Wasserstein-1 距離に固有のもので、Wasserstein-2 距離にも、KS 統計量にも、KL ダイバージェンスにもありません。なぜ数ある分布距離の中から Wasserstein-1 を選んだのか、その理由がこの第三の要件です。

---

## スライド 10: 理論基盤 — 治療効果異質性との連結
（想定時間: 2分）

では、その理論的連結を具体的に見てみましょう。

Kantorovich-Rubinstein の双対性定理が意味するのは、Wasserstein-1 距離は「変化率が1以下のあらゆる関数について、2つの分布での期待値の差の上限」に等しいということです。

これを CATE の文脈に適用します。CATE 関数が Lipschitz 定数 L を持つ、つまり effect modifier が1単位変化したときの治療効果の変化が最大で L であるとき、この定理から直接、heterogeneity bound が導かれます。

スライドの Proposition 2 の式が、本研究の中心的な結果です。この式が言っているのは、2地域間の平均治療効果の差は、L かける IQR かける nABCD で上界が与えられるということです。つまり、分布距離を測れば、治療効果の差の worst-case がわかる。この橋渡しこそが nABCD の理論的価値です。

---

## スライド 11: Clinical Calibration — Delta_max
（想定時間: 1.5分）

ここまでの理論を実務に結びつけるのが clinical calibration です。

先ほどの heterogeneity bound の右辺をそのまま Delta_max と定義します。これは、effect modifier 分布の差に起因する地域間治療効果差の worst-case upper bound です。

Calibration の手順は5ステップです。まず候補 effect modifier ごとに nABCD と bootstrap CI を算出します。次に先行研究から L を推定します。例えばサブグループ解析で、NIHSS が1点変わると治療効果がどれだけ変わるか、という情報です。そして Delta_max を算出し、その CI を導出します。最後に、全体の治療効果や非劣性マージンと並べて報告します。

ここで強調したいのは、これは固定閾値による二値判断ではないということです。ICH E17 が "similar enough" は文脈依存だと述べている以上、固定的な閾値では対応できません。Delta_max とその信頼区間を臨床的な文脈の中で解釈する、estimation-centered approach を取っています。

---

## スライド 12: L が未知の場合 — 感度分析
（想定時間: 1.5分）

ここまでは L がわかっている場合の話でしたが、実際の MRCT 計画段階では L が未知のケースの方が圧倒的に多いです。

そこで逆算アプローチを使います。臨床的に問題となる治療効果差 Delta_clin を設定して、「その差を生じさせるためには L がどれくらい必要か」を逆算します。この逆算値を L-star と呼びます。

L-star が妥当な範囲を超えて大きければ、分布差は臨床的に問題になりにくいと判断できます。逆に L-star が小さければ、小さな effect modification でも臨床的に問題が生じうるので、対策が必要です。

また、L が不明な場合の初期ガイダンスとして reference benchmarks も用意しています。nABCD が0.05未満なら negligible、0.05から0.15なら small、といった目安です。ただしこれはあくまで分布的な大きさの目安であって、臨床的意味はあくまで clinical calibration で決まることを改めて強調します。

## スライド 14: シミュレーション設計
（想定時間: 1分）

次にシミュレーションで推定性能を確認します。

8つのシナリオを設計しました。S1 は同一分布の null、S2 から S4 は位置ずれを0.2、0.5、1.0シグマと段階的に大きくしたもの、S5 は位置は同じで分散だけ1.5倍、S6 は形状差（正規対ガンマ）、S7 は歪度差（正規対対数正規）、S8 は位置と分散を同時に変えた複合シナリオです。

各シナリオで、地域あたりの n を50、100、200と変え、10,000反復で評価しました。bootstrap は2,000リサンプルです。これらのシナリオは MRCT で実際に観察されうる分布差のパターンを体系的にカバーしています。

## スライド 15: シミュレーション結果 — バイアスと被覆確率
（想定時間: 1.5分）

結果をまとめます。

まずバイアスについて。True nABCD が0.1以上のシナリオでは、n が100のとき、バイアスは0.02未満とほぼ無視可能でした。一方で S1 の null や S6 の形状シナリオのように、真の値がゼロに近い場合は、非負制約による正のバイアスが観察されます。これは Wasserstein 距離が本質的に非負であることから来る、境界付近の既知の現象です。

被覆確率については、実用上重要なシナリオ、つまり true nABCD が0.1以上のケースで、n が100のとき95% CI の被覆は概ね nominal に近い値でした。S3 で0.951、S4 で0.950、S7 で0.954です。

実務的な推奨として、地域あたり n が100以上あれば信頼性のある推定と推論が可能だと結論づけています。

## スライド 16: nABCD vs SMD — 感度比較
（想定時間: 1.5分）

次に、nABCD と SMD の感度を直接比較します。これがシミュレーションの最も重要な結果です。

S3 の位置差シナリオでは、nABCD も SMD もどちらも差を検出します。位置差に関しては両者は同等の情報を提供しています。

しかし S5 の尺度差、S6 の形状差、S7 の歪度差を見てください。SMD はすべてゼロのままです。一方で nABCD は S5 で0.136、S7 に至っては0.312 という大きな値を示しています。

特に S7 は注目に値します。対数正規分布は臨床的によく見られる分布形ですが、その分布差は SMD には完全に不可視です。nABCD が0.31 という、moderate から large の範囲にあるにもかかわらず、SMD はゼロ。これが SMD だけに頼る危険性の具体的な証拠です。

## スライド 18: 適用 — 2つの計画シナリオ
（想定時間: 1分）

ここからは実データへの適用です。

仮想的なシナリオとして、新規血栓溶解薬の Phase 3 MRCT を計画する状況を設定しました。2つの公開データセットを使って、MRCT 計画で実際に直面する2つの典型的なケースを示します。

Case A は IST-1 を用いた、effect modifier が未知のケースです。31カ国、約19,000人の試験で、治療と effect modifier の交互作用は検出されていません。L が推定できないので、L-star 感度分析で対応します。

Case B は IST-3 を用いた、effect modifier が特定済みのケースです。8カ国、約3,000人の試験で、NIHSS が交互作用 p = 0.001 と確認されており、L が推定可能です。こちらは clinical calibration で Delta_max を算出できます。

この2つのケースの対比が、nABCD フレームワークの柔軟性を示しています。

---

## スライド 19: Case A — IST-1 地理的分布異質性
（想定時間: 1.5分）

Case A の IST-1 です。31カ国のデータで年齢の分布パターンを見ると、非常に大きな地理的異質性が存在します。

最大の nABCD は India-UK ペアで0.565。これは IST-3 で観察された最大値の約4倍です。アジア諸国でも India が0.375、Singapore が0.205、Hong Kong が0.121と、地理的なクラスタリングが見えます。

L が不明なので、L-star 感度分析を行います。India-UK ペアで nABCD が0.565 のとき、Delta_max として2パーセントポイントの治療効果差を生じるために必要な L-star は、年あたり約0.005です。これは非常に小さな値です。つまり、年齢1歳あたり治療効果が0.5パーセントポイント変わるだけで、臨床的に問題になりうるということです。

L-star が小さいということは、分布異質性のリスクが高いことを意味します。この場合は層別ランダム化やプロトコルでの年齢制限といった、明示的な緩和策が必要です。

---

## スライド 20: Case B — IST-3 nABCD vs SMD の実データ比較
（想定時間: 1.5分）

Case B の IST-3 に移ります。8カ国、28ペアの比較を行いました。

Age、NIHSS、Treatment delay の3つの候補 effect modifier について nABCD を算出すると、中央値はいずれも0.1前後ですが、最大値は Age が0.285、NIHSS が0.240、Delay が0.195とばらつきがあります。

ここで注目していただきたいのが、SMD が見逃すケースです。Norway と Portugal の治療遅延を比べると、平均はほぼ同じ、4.34時間対4.33時間で、SMD は0.007。SMD で見れば同一分布と判断されます。しかし nABCD は0.069 で、形状差を検出しています。実は Norway は極端な右裾を持ち、歪度が6.76。対して Portugal はコンパクトな分布で歪度がマイナス0.23です。シミュレーションの S5 や S7 で見た現象が、まさに実データでも起きているわけです。

## スライド 21: Case B — Clinical Calibration 結果
（想定時間: 2分）

そして、ここが本日最も重要なスライドです。

NIHSS と Age の clinical calibration 結果を対比します。Age は nABCD が0.285 で NIHSS の0.240 より大きい。つまり分布距離だけで見れば、Age の方が異質性が大きいわけです。

ところが Delta_max を算出すると、話が逆転します。NIHSS の Delta_max は L-mean を使って5.02パーセントポイント。これは全体の治療効果 RD 約1.5パーセントポイントの3倍以上です。一方、Age の Delta_max はわずか0.47パーセントポイントです。NIHSS の10分の1以下です。

なぜこの逆転が起きるのか。NIHSS は交互作用が p = 0.001 で、L が大きい。つまり NIHSS の分布差は治療効果に大きなインパクトを持ちます。Age は交互作用が非有意で L が小さいため、分布差が大きくても臨床的な影響は限定的です。

これが本研究の核心的メッセージです。分布距離のランキングと臨床的インパクトのランキングは一致しません。nABCD の大きさだけでプーリングを判断してはいけない。clinical calibration を通じて初めて、臨床的に適切な判断が可能になるのです。

## スライド 23: 主要な知見と nABCD の3つの優位性
（想定時間: 1分）

Discussion に入ります。nABCD の3つの優位性をまとめます。

第一に、SMD が見逃す分布差を捕捉します。シミュレーションの S5、S6、S7 で確認し、IST-3 の Norway-Portugal で実データでも確認しました。

第二に、治療効果異質性への理論的連結があります。heterogeneity bound により Delta_max への定量的な橋渡しが可能です。KS 統計量や KL ダイバージェンスにはこの性質がありません。Wasserstein-1 固有の性質です。

第三に、bootstrap CI による統計的推論が可能です。視覚的検査、つまり目で見て分布が似ているかどうかを判断するアプローチと比べて、定量的で再現可能です。

---

## スライド 24: 実務への推奨
（想定時間: 1分）

実務への推奨をまとめます。

まず、候補 effect modifier ごとに nABCD と bootstrap CI を算出してください。地域あたり n は100以上を推奨します。L が推定可能なら Delta_max を算出し、L-max による保守的上界と L-mean による現実的推定の両方を提示してください。L が未知なら reference benchmarks と L-star 感度分析を組み合わせます。

重要なのは、Delta_max を単体で報告するのではなく、全体治療効果や非劣性マージンと並置して報告することです。文脈の中で解釈してこそ意味があります。

これは固定閾値に頼らない、文脈依存の臨床判断を支援するアプローチです。ICH E17 の "similar enough" を、定量的かつ臨床的に grounded な形で実装するものと位置づけています。

---

## スライド 25: まとめ
（想定時間: 1分）

最後にまとめです。

nABCD は ICH E17 における定量的方法論の欠如というギャップを埋めます。計画段階で利用可能であり、事前の臨床試験データだけでなく、レジストリや RWE データからも算出できます。

本日お伝えしたかったメッセージは2つです。1つ目は、heterogeneity bound という式に集約されています。分布距離から治療効果差の upper bound が導けるという理論的基盤です。

2つ目は、分布距離のランキングと臨床的インパクトのランキングは一致しないということ。IST-3 で見たように、nABCD が大きくても L が小さければ臨床的影響は小さく、nABCD が中程度でも L が大きければ臨床的影響は甚大です。nABCD の大きさだけでなく、clinical calibration が判断の鍵です。
