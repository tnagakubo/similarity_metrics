# 多地域臨床試験における地域プーリングのための効果修飾因子類似性の定量化

**Quantifying Effect Modifier Similarity for Regional Pooling in Multi-Regional Clinical Trials**

---

## 要旨（Abstract）

ICH E17ガイドラインは、多地域臨床試験（MRCT）における地域プーリングを効果修飾因子（EM）分布の類似性に基づいて行うことを推奨しているが、そのような類似性を定量化する具体的な方法論は示されていない。既存のアプローチは位置差（標準化平均差）に焦点を当てるか、解釈可能なスケールを欠いている（Kolmogorov–Smirnov統計量）。本論文では、**正規化累積分布間面積**（normalized Area Between Cumulative Distributions; nABCD）を提案する。nABCDは、2つの分布間のWasserstein-1距離をプールされた四分位範囲の2倍で除したものとして定義される。

治療効果異質性バウンド（heterogeneity bound）との接続を通じて、nABCDは**臨床較正**（clinical calibration）を可能にする：地域間の最大潜在的治療効果差（$\Delta_{\max}$）は、nABCD、プールIQR、およびEMのCATE感度の関数として表現でき、ブートストラップ信頼区間が推定の不確実性を定量化する。

8つのシナリオ（位置シフト、スケール差、歪み分布、複合パターンを含む）にわたるシミュレーション研究は、MRCT地域サブグループに典型的なサンプルサイズにおいて、パーセンタイルブートストラップ推定量の十分なバイアスおよびカバレッジを実証した。標準化平均差とは異なり、nABCDは位置のみの指標では見えない分散、形状、歪度の差を捉えた。

糖尿病MRCTへの適用は、臨床較正が文脈依存的な解釈を提供することを示した：弱い効果修飾因子（BMI: nABCD = 0.51, $\Delta_{\max}$ = 0.16%）における大きな分布差は、強い効果修飾因子（ベースラインHbA1c: nABCD = 0.27, $\Delta_{\max}$ = 0.24%）における中程度の分布差よりも臨床的重みが小さく、**分布の大きさと臨床的影響は根本的に異なる次元**であることを実証した。

nABCDフレームワークは、分布差を臨床スケール上の潜在的治療効果異質性に変換することにより、ICH E17実装における方法論的ギャップを埋め、エビデンスに基づくプーリング決定を支援する。

**キーワード**: 多地域臨床試験、ICH E17、効果修飾因子、Wasserstein距離、地域プーリング、分布類似性

## 1. 序論（Introduction）

### 1.1 多地域臨床試験の背景

多地域臨床試験（MRCT）は、単一のプロトコルのもとで複数の国または規制地域にわたって実施される試験であり、グローバル医薬品開発の標準パラダイムとなっている (Chen 2010; Quan 2010)。このアプローチは、タイムラインの短縮、一般化可能性の拡大、世界中の患者への新規治療への早期アクセスという大きな利点を提供する。2017年に採択されたICH E17ガイドラインは、MRCTの計画・設計の原則を確立し、治療効果がターゲット集団全体に一般化可能であるという中心的な仮定を置いた (ICH E17)。

### 1.2 地域プーリングとEM分布の類似性

治療成果における地域的一貫性を評価する能力を高めるための主要戦略が、**地域プーリングアプローチ**（regional pooling approach）である。これは、類似した患者特性を持つ地域を分析のためにグループ化するものである (ICH E17)。ICH E17ガイドラインは、プーリング決定を効果修飾因子（EM）分布の類似性に基づいて行うことを明示的に推奨している：

> 「疾患および/または研究対象薬物に関連する内因性および/または外因性因子に関して、被験者が**十分に類似している**と考えられる場合、地域はランダム化および/または解析のためにプーリングしてもよい。」（ICH E17, Section 2.2.5）

**効果修飾因子**（effect modifier）とは、年齢、疾患重症度、遺伝子マーカーなどのベースライン患者特性であり、これらについて治療効果がサブグループ間で異なるものをいう。例えば、若年患者が高齢患者よりも治療に良好に反応する場合、年齢は効果修飾因子である。このような異質性が存在する場合、たとえ薬剤が個人レベルで同一に作用しても、異なる患者構成を持つ地域は異なる平均治療効果を観察しうる。主に若年患者で構成される地域は、薬剤の作用が異なるからではなく、**患者ミックスが異なるため**に、より大きな効果を示すことになる。

### 1.3 方法論的ギャップ

EM分布の類似性の規制上の重要性にもかかわらず、現在の実務には標準化された定量的方法論が欠如している。ICH E17ガイドラインは、分布が「十分に類似している」かどうかを判断するための特定の指標、閾値、統計的手順を提供していない。

Songら (2025)は、中国NMPA（国家医薬品監督管理局）の観点からICH E17実装における定量的ツールなしにプーリング基準を運用する課題を指摘している。Longら (2025)は、ICH E17に基づく一貫性評価の基本的考慮事項をさらに議論している。

**表1: 分布類似性評価における現行アプローチの限界**

| 方法 | 限界 |
|------|------|
| 目視検査 | 主観的、再現性なし |
| 標準化平均差（SMD） | 位置のみ捕捉、スケール・形状を無視 |
| Kolmogorov–Smirnov統計量 | 意思決定のための解釈可能なスケールなし |

### 1.4 本論文の目的

本論文は、地域間のEM分布を比較するための指標である**正規化累積分布間面積**（nABCD）と、分布差を治療成果スケール上の潜在的治療効果異質性に変換する**臨床較正フレームワーク**（clinical calibration framework）を提案することにより、この方法論的ギャップに対処する。

本研究の具体的な研究課題は：

> **地域間の分布類似性をスケールフリーな方法で推定し、その推定値を潜在的治療効果異質性に関する臨床的に解釈可能な情報に変換するにはどうすればよいか？**

重点は**推定と臨床的解釈**にあり、仮説検定ではない。二値的な受容/棄却ルールではなく、審議に情報を提供する定量的ツールを規制科学者に提供することを目指す。この設計哲学は、プーリング決定が閾値の機械的適用ではなく文脈的判断を必要とするというICH E17の原則を反映している。

### 1.5 nABCDフレームワークの4つの貢献

1. **完全な分布比較**: Wasserstein-1距離は、位置、スケール、形状の差を同時に捕捉する (Panaretos & Zemel 2019)
2. **スケールフリーな推定**: IQRによる正規化は無単位の尺度を生み出し、異なるスケールで測定されたEM間の比較を可能にする。ブートストラップ信頼区間が推定の不確実性を定量化する
3. **臨床較正**: 異質性バウンド（Proposition 2）を通じて、nABCD推定値を各EMの臨床的文脈に特有の潜在的治療効果差（$\Delta_{\max}$）に変換でき、主要アウトカムスケールで表現される (Pearl 2011)
4. **感度分析**: 較正がCATE感度パラメータ $L$ に依存し、$L$ が不確実でありうるため、フレームワークは $L$ に関する感度分析を自然に収容し、単一の二値検定よりも豊富なエビデンス基盤を提供する

以下の構成で述べる。第2節で方法論的フレームワーク、第3節でシミュレーション研究、第4節でMRCTデータセットへの適用、第5節で考察・限界・今後の方向性を議論する。

## 2. 方法（Methods）

### 2.1 nABCD指標

#### 2.1.1 効果修飾因子と地域平均治療効果

効果修飾因子（EM）は、治療効果がサブグループ間で変動するベースライン患者特性である。形式的に、条件付き平均治療効果（CATE）を $\tau(x) = E[Y(1) - Y(0) \mid X = x]$ と表記する。ここで $X$ は効果修飾因子である。この関数が非定数の場合、地域 $r$ で観察される平均治療効果は、その地域におけるEMの分布 $F_r$ に依存する：

$$\bar{\tau}_r = \int \tau(x) \, dF_r(x) \tag{1}$$

#### 2.1.2 異質性バウンドとWasserstein-1距離

CATE関数がLipschitz定数 $L$ で有界であるとき、地域平均治療効果の差は以下でバウンドされる：

$$|\bar{\tau}_1 - \bar{\tau}_2| \leq L \cdot W_1(F_1, F_2) \tag{2}$$

ここで $W_1(F_1, F_2)$ は地域1と2のEM分布間のWasserstein-1距離を表す。

**Wasserstein-1距離**（Earth Mover's Distanceとも呼ばれる）は、2つの累積分布関数 $F$ と $G$ に対して以下のように定義される (Villani 2009)：

$$W_1(F, G) = \int_{-\infty}^{\infty} |F(x) - G(x)| \, dx \tag{3}$$

幾何学的に、これは2つのCDF間の**総面積**に等しい（図1）。標準化平均差とは異なり、Wasserstein距離は分散、歪度、その他の分布特性の変化に応答する (Panaretos & Zemel 2019)。

**なぜ $W_1$ を使用するか**: 式(2)の Lipschitzバウンドは、$W_1$ 距離を特に要求する。Kantorovich–Rubinstein双対性により、

$$W_1(F_1, F_2) = \sup_{\|f\|_{\text{Lip}} \leq 1} \left|\int f \, dF_1 - \int f \, dF_2\right|$$

が成り立ち、これはLipschitz連続関数（CATEを含む）と分布距離を直接結びつける (Villani 2009)。$W_2$ 距離はガウス族に対して閉じた形の表現を許すが、Lipschitz関数による双対特性を持たず、したがって臨床較正フレームワークの中核である異質性バウンドを提供できない。

#### 2.1.3 nABCDの定義

**正規化累積分布間面積**（nABCD）は、Wasserstein-1距離をプールされた四分位範囲の2倍で正規化したものとして定義される：

$$\text{nABCD}(F_1, F_2) = \frac{W_1(F_1, F_2)}{2 \cdot \text{IQR}_{\text{pooled}}} \tag{4}$$

ここでプールIQRは結合サンプルから計算される。IQRに基づく正規化は、**スケールフリーな解釈**を可能にし、外れ値に頑健であり、分布差を散布度の単位で表現する。

**Proposition 1（非負性）**: 有限IQRを持つ分布に対して $\text{nABCD} \geq 0$ であり、$F_1 = F_2$ の場合にのみ等号が成立する。

**Proposition 2（異質性との接続）**: CATE関数がLipschitz定数 $L$ を持つとき、

$$|\bar{\tau}_1 - \bar{\tau}_2| \leq 2L \cdot \text{IQR}_{\text{pooled}} \cdot \text{nABCD}(F_1, F_2) \tag{5}$$

**証明**: 式(4)を式(2)に代入すると、$|\bar{\tau}_1 - \bar{\tau}_2| \leq L \cdot W_1 = L \cdot 2 \cdot \text{IQR}_{\text{pooled}} \cdot \text{nABCD} = 2L \cdot \text{IQR}_{\text{pooled}} \cdot \text{nABCD}$ を得る。□

### 2.2 推定（Estimation）

地域1からのサンプル $\{X_{1,i}\}_{i=1}^{n_1}$ および地域2からのサンプル $\{X_{2,j}\}_{j=1}^{n_2}$ が与えられたとき、nABCDは経験分布関数を用いて推定される：

$$\widehat{\text{nABCD}} = \frac{\sum_{k=1}^{n_1+n_2-1} |\hat{F}_1(x_{(k)}) - \hat{F}_2(x_{(k)})| \cdot (x_{(k+1)} - x_{(k)})}{2 \cdot \widehat{\text{IQR}}_{\text{pooled}}} \tag{6}$$

ここで $x_{(1)} < \cdots < x_{(n_1+n_2)}$ は結合順序統計量である。

**計算量**: $O((n_1 + n_2) \log(n_1 + n_2))$、ソートに支配される。

推論にはノンパラメトリック**パーセンタイルブートストラップ**を用い (del Barrio et al. 1999; Sommerfeld & Munk 2018)、$B = 2{,}000$ 反復を使用する。

### 2.3 解釈と臨床較正

nABCDの中心的特徴は、Proposition 2を通じた治療効果異質性との接続である。この接続は、固定閾値のみへの依存ではなく、臨床的に根拠のある解釈フレームワークの基盤を提供する。

#### 2.3.1 異質性バウンドを介した臨床較正

式(5)より、EM分布差に起因する地域平均治療効果の最大潜在差は：

$$\Delta_{\max} = 2L \cdot \text{IQR}_{\text{pooled}} \cdot \text{nABCD}(F_1, F_2) \tag{7}$$

ここで $L$ はEMに対するCATE関数 $\tau(x)$ のLipschitz定数であり、そのEMに対する治療効果の臨床的感度を反映する。$L$ を感度パラメータとして用いるアプローチは、Armstrong & Kolesár (2021) が提案したフレームワークに従い、妥当なLipschitz定数の範囲について信頼区間を報告することを推奨している。

**臨床較正の手順**：

1. 候補EMを特定し、各EMについて地域ペアごとにブートストラップCIつきのnABCDを計算
2. 各EMについて、事前知識からLを推定またはバウンド（例：サブグループ解析でEMの単位変化あたり $\Delta\tau$ の治療効果変動が示されている場合、$L \approx \Delta\tau / \Delta x$）
3. 式(7)を用いて $\Delta_{\max}$ を計算。これは分布差に起因する最悪ケースの治療効果差を表す
4. nABCD信頼区間から $\Delta_{\max}$ のブートストラップCIを導出：$[\Delta_{\max,L}, \Delta_{\max,U}] = 2L \cdot \text{IQR}_{\text{pooled}} \cdot [\text{nABCD}_L, \text{nABCD}_U]$
5. $\Delta_{\max}$ とそのCIを臨床的文脈（全体治療効果サイズ、非劣性マージン、最小臨床重要差など）とともに報告

この**推定中心のアプローチ**は、プーリング決定を二値的仮説検定のフレームワークに押し込めることを意図的に回避する。その理由は3つある：

- ICH E17ガイドラインは「十分に類似」を本質的に文脈依存的と記述しており、棄却閾値への還元は過度の単純化のリスクがある
- $L$ の不確実性は、$\Delta_{\max}$ 自体が感度分析の対象であることを意味する
- p値や棄却/非棄却の結果よりも、CIつきの $\Delta_{\max}$ の方が規制審議により豊富な情報を提供する (Wasserstein 2016)

#### 2.3.2 参照ベンチマーク

$L$ の事前知識が利用できない場合、以下のベンチマークが初期評価のための便宜的参照を提供する。

**表2: $L$ が未知の場合のnABCD値の参照ベンチマーク**

| nABCD範囲 | 解釈 | 推奨アクション |
|-----------|------|----------------|
| < 0.05 | 無視できる差 (Negligible) | プーリングは広く支持可能 |
| 0.05–0.15 | 小さな差 (Small) | プーリングは一般的に許容可能 |
| 0.15–0.30 | 中程度の差 (Moderate) | 臨床較正を実施 |
| > 0.30 | 大きな差 (Large) | 臨床較正が必須 |

> **注**: これらのベンチマークは中程度のCATE感度を仮定した分布の大きさを記述するものであり、臨床的有意性を示すものではない。同じnABCD値であっても、CATE感度 $L$ に応じて、あるEMでは無視でき、別のEMでは重大となりうる。可能な限り臨床較正（式7）を使用すべきである。

## 3. シミュレーション研究（Simulation Study）

nABCD推定量の推定特性（バイアス、変動性、ブートストラップ信頼区間のカバレッジ確率）を評価するためにシミュレーション研究を実施した。これらの特性は臨床較正フレームワークにとって本質的に重要であり、nABCDの信頼性のある推定が $\Delta_{\max}$ 推定の質を直接決定する。

### 3.1 シミュレーション設計

#### 3.1.1 シナリオ

方法論的検証のために8つの系統的シナリオを設計し、位置、スケール、形状、およびそれらの組み合わせにわたる制御された分布差を検討した。

#### 3.1.2 シミュレーションパラメータ

- **サンプルサイズ**: 各地域 $n = 50, 100, 200$（MRCTの地域サブグループに典型的なサイズを反映）
- **反復数**: シナリオ×サンプルサイズの組み合わせごとに10,000回（全報告割合のモンテカルロ標準誤差が0.005未満となるよう保証）
- **ブートストラップ**: $B = 2{,}000$ リサンプル
- **ソフトウェア**: R version 4.3.3

#### 3.1.3 評価指標

推定中心のフレームワークに一致して、以下を評価した：

1. **バイアス**: $\text{Mean}(\widehat{\text{nABCD}}) - \text{nABCD}$
2. **平均二乗誤差平方根 (RMSE)**: $\sqrt{\text{Mean}[(\widehat{\text{nABCD}} - \text{nABCD})^2]}$
3. **カバレッジ確率**: 真値を含む95%ブートストラップCIの割合
4. **CI幅**: ブートストラップCIの平均幅（推定精度を反映）

### 4.1 2型糖尿病MRCT

nABCD臨床較正フレームワークを、3地域（日本 $n=150$、米国 $n=200$、EU $n=180$）の2型糖尿病における仮想的MRCTを用いて説明する。主要評価項目は24週時のHbA1c変化量（%）であり、全体治療効果は $-0.8$%、事前設定された非劣性マージンは $\Delta_{\text{clin}} = 0.4$% HbA1cである。

**表8: 仮想的糖尿病MRCTにおける地域別ベースライン特性**

| 特性 | 日本 ($n=150$) | 米国 ($n=200$) | EU ($n=180$) |
|------|----------------|----------------|--------------|
| 年齢, 平均 (SD) | 62.3 (10.2) | 58.7 (11.5) | 60.1 (10.8) |
| BMI, 平均 (SD) | 24.8 (3.2) | 32.1 (5.8) | 29.4 (4.9) |
| HbA1c, 平均 (SD) | 7.6 (0.9) | 8.4 (1.3) | 8.1 (1.1) |

**表9: ペアワイズnABCD値と95%ブートストラップ信頼区間**

| 効果修飾因子 | 日本 vs 米国 | 日本 vs EU | 米国 vs EU |
|--------------|-------------|-----------|-----------|
| 年齢 | 0.12 (0.07–0.18) | 0.08 (0.04–0.13) | 0.05 (0.02–0.09) |
| BMI | 0.51 (0.44–0.58) | 0.38 (0.31–0.45) | 0.18 (0.12–0.24) |

### 4.2 臨床較正

nABCD値だけではプーリング決定を決められない。第2.3節の臨床較正手順を適用して、分布差を潜在的治療効果異質性に変換する。

**Step 1: 各EMのCATE感度 $L$ を推定**

糖尿病試験の公表されたサブグループ解析に基づき、CATE関数のLipschitz定数の推定値を採用する：

- **年齢**: $L_{\text{age}} \approx 0.01$% HbA1c/年 — サブグループ解析は通常、控えめな年齢–治療相互作用を示し、10歳あたり約0.1% HbA1cの治療効果変動
- **BMI**: $L_{\text{BMI}} \approx 0.02$% HbA1c/(kg/m²) — DPP-4阻害薬の有効性に関する回帰分析で、HbA1c低下に対するBMI係数を $-0.02$/(kg/m²)と推定 ($p = 0.024$) (Kim et al. 2015)
- **HbA1c**: $L_{\text{HbA1c}} \approx 0.3$% HbA1c/(%HbA1c) — ベースラインHbA1cはほとんどの血糖降下療法にとって最も強い効果修飾因子：DPP-4阻害薬98試験のメタ回帰でベースライン1%高いあたり0.4–0.5%ポイントのHbA1c低下増大 (Craddy et al. 2014)、GLP-1受容体作動薬試験で平均への回帰を補正後 $\beta = -0.31$/(%HbA1c) (Jones et al. 2016)

**Step 2: 最大乖離地域ペアの $\Delta_{\max}$ を計算**

**表10: 日本–米国比較のnABCD臨床較正**

| EM | nABCD | $L$ | IQR(pooled) | $\Delta_{\max}$ | vs $\Delta_{\text{clin}}$ |
|----|-------|-----|-------------|-----------------|---------------------------|
| 年齢 | 0.12 | 0.01 | 14.2年 | 0.03% | ≪ 0.4% |
| BMI | 0.51 | 0.02 | 7.8 kg/m² | 0.16% | < 0.4% |
| HbA1c | 0.27 | 0.30 | 1.5% | 0.24% | < 0.4% |

> $\Delta_{\max} = 2 \times L \times \text{IQR}_{\text{pooled}} \times \text{nABCD}$（式7）。$\Delta_{\text{clin}} = 0.4$% HbA1c（非劣性マージン）。

**Step 3: 臨床的文脈での $\Delta_{\max}$ の解釈**

較正は、nABCD単独ではなく臨床的文脈が解釈を駆動しなければならない理由を示す微妙な全体像を明らかにする：

- **年齢** (nABCD = 0.12): $\Delta_{\max} = 0.03$% — 全体治療効果 ($-0.8$% HbA1c) の4%未満、非劣性マージンの8%未満。年齢はこの薬効群に対して弱い効果修飾因子であり、地域間の分布差は**無視できる潜在的異質性**に変換される

- **BMI** (nABCD = 0.51): 大きな分布差にもかかわらず、$\Delta_{\max} = 0.16$%、全体治療効果の20%。BMIの低いCATE感度 ($L = 0.02$) は、かなりの分布差があっても治療効果異質性への影響が限定的であることを意味する。参照ベンチマークだけでは「大きな差」と示唆されるが、**BMIと治療応答の弱い関係を見落とす**

- **HbA1c** (nABCD = 0.27): $\Delta_{\max} = 0.24$% — 全体治療効果の30%、非劣性マージンの**60%**に達する。nABCDはBMIより小さいにもかかわらず、ベースラインHbA1cの強いCATE感度 ($L = 0.30$) は、中程度の分布差がより大きな臨床的重みを持つことを意味する。**この比較は慎重な審議を必要とする**

### 4.3 ランキングの逆転

この例は、nABCDの臨床的意味がEMの効果修飾因子としての役割に依存することを実証している：

- **BMI**: 最大の分布差 (nABCD = 0.51) → **最小の**臨床的影響 ($\Delta_{\max} = 0.16$%)
- **HbA1c**: 中程度の分布差 (nABCD = 0.27) → **最大の**臨床的影響 ($\Delta_{\max} = 0.24$%)

> **分布距離と臨床的関連性は根本的に異なる次元である**

### 4.4 感度分析

$L$ が不確実な場合、妥当な値に対する感度分析が不可欠である。

**表11: ベースラインHbA1cのCATE感度 $L$ の関数としての $\Delta_{\max}$**
（日本 vs 米国, nABCD = 0.27, IQR = 1.5%）

| $L$（仮定） | $\Delta_{\max}$ | 治療効果の% |
|-------------|-----------------|------------|
| 0.10 | 0.08% | 10% |
| 0.20 | 0.16% | 20% |
| 0.30 | 0.24% | 30% |
| 0.40 | 0.32% | 40% |
| 0.50 | 0.41% | 51% |

> $L^* = \Delta_{\text{clin}} / (2 \cdot \text{IQR} \cdot \text{nABCD}) = 0.49$ — $\Delta_{\max}$ が非劣性マージン0.4%と等しくなるCATE感度。

感度分析は、臨床試験設計者と規制当局に透明なビューを提供する：このEMと地域ペアについて、どのレベルのCATE感度で分布差が臨床的に重要になり始めるか？

## 5. 考察（Discussion）

### 5.1 主要な貢献

MRCTにおけるEM分布を比較するための正規化指標nABCDを開発・検証した。貢献は以下の通り：

1. Wasserstein-1距離とIQR正規化を組み合わせた原理に基づく指標
2. 異質性バウンドを通じてnABCDと治療効果異質性を接続する理論的フレームワーク
3. CATE感度を用いてnABCD値を文脈特異的な評価に変換する臨床較正手順
4. シミュレーションによる厳密な検証

### 5.2 既存手法との比較

- **SMD vs nABCD**: nABCDは分散と形状を含む完全な分布差を捕捉。シミュレーションでは、SMD推定値がゼロ付近に留まったスケール差（S5）、形状差（S6）、歪度差（S7）をnABCDが検出
- **KS統計量 vs nABCD**: nABCDは異質性バウンド（式7）を通じて治療効果異質性への直接的接続を提供し、純粋に統計的な評価ではなく臨床較正を可能にする
- **目視検査 vs nABCD**: nABCDは客観的かつ再現可能

### 5.3 なぜKullback–Leibler divergenceではなくWasserstein距離か

KLダイバージェンスは情報理論における分布差の自然な尺度であるが、本応用にはいくつかの構造的限界がある：

1. **非対称性**: $D_{\text{KL}}(P \| Q) \neq D_{\text{KL}}(Q \| P)$ — 地域Aと地域Bの比較値が逆方向と異なる。MRCTにおける地域プーリング決定の対称的性質と矛盾する
2. **発散**: $Q$ のサポートが $P$ のサポートをカバーしない場合に無限大に発散。経験分布では頻繁に起こり、密度推定とバンド幅選択が必要となり、追加のチューニングパラメータが導入される
3. **Lipschitzバウンドの欠如**: Kantorovich–Rubinstein双対定理はWasserstein距離がLipschitz連続関数の期待値の差をバウンドすることを保証し、Proposition 2の異質性バウンドを可能にする。KLダイバージェンスにはLipschitz連続CATE関数に対する治療効果異質性に直接結びつく類似の結果がない (Gibbs & Su 2002)

Wasserstein距離は三角不等式を満たす真の距離であり、弱収束を計量化する (Villani 2008)。

### 5.4 臨床較正の意義

第2.3節で導入した臨床較正手順は、固定閾値アプローチからの転換を表す。Cohenの$d$ベンチマーク（小=0.2, 中=0.5, 大=0.8）は文脈フリーな適用に対して広く批判されており、このパターンを意図的に回避している。

適用例は**ランキングの逆転**を明らかにした：BMIが最大の分布差（nABCD = 0.51）を示しつつ最小の臨床的影響（$\Delta_{\max} = 0.16$%）、一方でベースラインHbA1cが中程度の分布差（nABCD = 0.27）を示しつつ最大の臨床的影響（$\Delta_{\max} = 0.24$%）。この逆転は、**分布距離と臨床的関連性が根本的に異なる次元**であることを裏付ける。

### 5.5 実務上の推奨

1. 各候補EMについて、地域ペアごとにブートストラップCIつきnABCDを計算（$n \geq 100$）
2. 式(7)を用いてnABCDを臨床アウトカムスケール上の $\Delta_{\max}$ とそのCIに変換（CATE感度 $L$ の事前知識を組み込む）
3. $\Delta_{\max}$ とそのCIを全体治療効果、非劣性マージン等の臨床的関連ベンチマークとともに報告
4. $L$ が不確実な場合、妥当な $L$ 値にわたる感度分析を実施（表11）
5. $L$ が推定不可能な場合、初期ガイダンスとして参照ベンチマーク（表2）を使用（臨床較正が意思決定のより厳密な基盤を提供することを認識しつつ）

### 5.6 複数EMの同時評価

実務では複数の候補EMが同時に評価されうる。nABCDフレームワークは各EMを個別に評価し、すべての候補EMについて全地域ペアにわたる $\Delta_{\max}$ とそのCIの報告を推奨する。

全体的なプーリング推奨に至るには：
- **保守的アプローチ**: 全EMおよび地域ペアにわたる最大 $\Delta_{\max}$ に基づく
- **エビデンスの総体アプローチ**: $\Delta_{\max}$ 値のコレクション、不確実性、各 $L$ 推定の信頼性を総合的に判断

### 5.7 限界

1. **連続EMのみ**: カテゴリカルまたは混合型EMへの拡張にはさらなる開発が必要
2. **単変量**: nABCDは各EMを個別に評価。多変量拡張がEM間の交絡に対処する
3. **バイアス特性**:
   - 帰無仮説下の小サンプル（$n < 100$）で正のバイアスがnABCD推定値を膨張させうる
   - 大きな真値（S4, nABCD = 0.372）で持続する負のバイアスが漸進的なアンダーカバレッジに繋がる（$n=200$で0.740）
   - 境界効果はWasserstein距離の関数としてのnABCDの非負・有界性に固有
   - $n \geq 100$（各地域）で信頼性のある点推定とCIを推奨。真のnABCDが約0.3を超える場合、カバレッジが劣化する可能性に注意
4. **$L$ の必要性**: 臨床較正にはCATE感度 $L$ の推定が必要であり、事前データから常に利用可能とは限らない

### 5.8 今後の展望

- 多変量拡張
- 小サンプル用バイアス修正法
- 実際のMRCTデータを用いたCATE感度パラメータの経験的較正
- 歴史的試験データベースからの $L$ 推定法
- 経時的EM分布の動的類似性評価への拡張

### 5.9 結論

nABCDは、分布類似性を評価するための原理に基づくフレームワークを提供することにより、ICH E17実装における方法論的ギャップを埋める。「十分に類似」を固定閾値に還元するのではなく、臨床較正手順が分布差を潜在的治療効果異質性の文脈特異的な評価に変換し、エビデンスに基づく臨床的に根拠のあるプーリング決定を可能にする。オープンソースRコードが採用の促進のために利用可能である。

## 付録

### 付録A: 証明と数学的詳細

#### A.1 Proposition 1の証明（非負性）

非負性はWasserstein-1距離の非負性から直接従う：$W_1(F_1, F_2) = \int |F_1(x) - F_2(x)| \, dx \geq 0$ であり、すべての $x$ について $F_1(x) = F_2(x)$ の場合にのみ等号が成立する。非退化分布に対して $\text{IQR}_{\text{pooled}} > 0$ であるから、比率 $\text{nABCD} = W_1 / (2 \cdot \text{IQR}_{\text{pooled}}) \geq 0$ である。

#### A.2 漸近的性質

標準的な正則条件のもとで、経験的Wasserstein-1距離 $W_1(\hat{F}_1, \hat{F}_2)$ は $W_1(F_1, F_2)$ の一致推定量である (del Barrio et al. 1999)。経験的IQRの一致性と組み合わせて、$\widehat{\text{nABCD}}$ は $\text{nABCD}(F_1, F_2)$ の一致推定量である。

一次元では、経験的 $W_1$ 距離は対数修正なしに $O(n^{-1/2})$ のレートで収束する (del Barrio et al. 1999)。$F_1 \neq F_2$ の二標本推定で有限二次モーメントのもと、$\sqrt{n}(W_1(\hat{F}_{1,n_1}, \hat{F}_{2,n_2}) - W_1(F_1, F_2))$ は平均ゼロのガウシアンに分布収束する。経験的IQRも標準的な密度条件のもとで $O(n^{-1/2})$ で収束するため、比率 $g(w, q) = w/(2q)$ に対するデルタ法により $\widehat{\text{nABCD}}$ の漸近正規性を得る：

$$\sqrt{n}\bigl(\widehat{\text{nABCD}} - \text{nABCD}(F_1, F_2)\bigr) \xrightarrow{d} N(0, \sigma^2_{\text{nABCD}})$$

この結果は $\text{nABCD} > 0$（すなわち $F_1 \neq F_2$）を要求する。境界 $F_1 = F_2$ では標準的漸近論は適用されない。

ブートストラップは緩い条件のもとでWasserstein距離に対する妥当な推論を提供する (Sommerfeld & Munk 2018)。

### 付録B: nABCD計算のRコード

```r
compute_nABCD <- function(x1, x2) {
  pooled <- c(x1, x2)
  iqr_pooled <- IQR(pooled)
  if (iqr_pooled == 0) return(NA)
  all_vals <- sort(unique(pooled))
  F1 <- ecdf(x1); F2 <- ecdf(x2)
  w1 <- sum(diff(all_vals) *
    abs(F1(all_vals[-length(all_vals)]) -
        F2(all_vals[-length(all_vals)])))
  w1 / (2 * iqr_pooled)
}

nABCD_bootstrap <- function(x1, x2,
    B = 2000, conf = 0.95) {
  obs <- compute_nABCD(x1, x2)
  boot_vals <- replicate(B, {
    b1 <- sample(x1, replace = TRUE)
    b2 <- sample(x2, replace = TRUE)
    compute_nABCD(b1, b2)
  })
  alpha <- 1 - conf
  ci <- quantile(boot_vals,
    c(alpha/2, 1 - alpha/2), na.rm = TRUE)
  list(estimate = obs,
       ci_lower = ci[1], ci_upper = ci[2])
}
```
