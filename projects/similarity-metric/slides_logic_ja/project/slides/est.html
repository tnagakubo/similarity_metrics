3 ｜ 読み方

推定は、経験分布と percentile bootstrap で行う

点推定

経験分布の差を積分

二地域の経験分布関数の差の絶対値を足し上げる

95% 信頼区間

percentile bootstrap

地域ごとに独立に再抽出し、2,000 回の 2.5・97.5 パーセンタイルを取る

注意点

上方に偏る

距離は負にならない。同じ分布の二地域でも正の値が出る

次に、データからどう推定するかです。点推定は単純で、二つの地域の経験分布関数の差の絶対値を積分します。信頼区間は percentile bootstrap です。各地域を独立に、元のサイズで再抽出することを 2,000 回繰り返し、その 2.5 パーセンタイルと 97.5 パーセンタイルを区間にします。分散の推定が要らないことが、この方法を選ぶ理由です。一つ注意があります。距離は負にならないので、推定値は常に上に偏ります。二つの地域が全く同じ分布から来ていても、推定値は正になります。この性質への対処が、次のスライドです。
