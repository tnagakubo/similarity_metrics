2 ｜ 物差し

既存の指標は、それぞれ何かが足りない

指標捉えるもの足りない点
SMD（標準化平均差）位置（平均）の差広がりや形の差に反応しない
KS 統計量分布全体の差臨床的に解釈できる尺度を持たない
KL divergence分布全体の差非対称で、密度推定が必要。小標本では実用的でない

例：N(50, 5²) と N(50, 15²) は広がりが 3 倍違うのに、SMD は 0

ここから方法です。まず既存の選択肢を並べます。SMD、標準化平均差は平均の差しか見ないので、平均が同じで広がりが 3 倍違う二つの分布でもゼロになります。KS 統計量は分布全体の差を捉えますが、臨床的に解釈できる尺度を持ちません。KL divergence は非対称で、経験分布どうしでは発散しやすく、密度推定も必要なので、地域ごとの小さい標本では実用的ではありません。それぞれ何かが足りない、というのがこのスライドの要点です。
