考察

限界は、置いた前提に由来する

対象の範囲

連続な効果修飾因子を一つずつ扱う。カテゴリ変数と多変量は今後の課題

小さい距離での推定

上方バイアスと被覆不足がある。0〜0.2 SD にはシミュレーションの裏付けがない

共通 CATE の前提

地域によって τ 自体が変わる要因や、未測定の効果修飾因子は測れない

Lipschitz の前提

定数 L は臨床判断。閾値型の CATE では上界は緩いが、過小評価はしない

限界は四つにまとめられます。一つ目、対象は連続な効果修飾因子を一つずつで、カテゴリ変数や多変量への拡張は今後の課題です。二つ目、距離が小さいところでは上方バイアスと被覆不足があります。特に 0 から 0.2 SD の範囲にはシミュレーションの設定がなく、応用例で差ありと判定された距離の多くがそこに入るので、その区間は裏付けなしに読んでいる、と論文は明記しています。三つ目、上界は治療効果の関数が全地域で共通であることを前提にしています。医療環境のように関数自体を変える要因や、測っていない効果修飾因子は対象外です。四つ目、Lipschitz の前提です。定数 L は臨床判断であり、結論はそれに条件づけられます。また、ある値を境に効果が急に変わる閾値型の関数では L が大きくなり、上界は緩くなります。ただしこれは最悪の場合を押さえるという設計の帰結で、差を過小評価する方向には働きません。
