結論

差を定量化する。併合の判断は臨床に残す

W₁ は「十分に似ているか」という判断への定量的な入力であり、判定規則ではない

物差し

因子ごとの W₁

元の測定単位のまま

翻訳

Δmax、参照距離

定数は臨床勾配

読み方

区間と null floor

不確かさを付けて読む

まとめます。この論文が提供するのは、効果修飾因子ごとの W₁ という物差し、それを臨床勾配で効果差の尺度に翻訳する較正、そして信頼区間と null floor による読み方、の三点です。論文は差を定量化しますが、どこまで似ていれば併合してよいか、という規則は定めません。その判断は、臨床と規制の総合的な評価に残します。W₁ はその判断を支える定量的な入力である、というのが論文の結論です。以上です。
