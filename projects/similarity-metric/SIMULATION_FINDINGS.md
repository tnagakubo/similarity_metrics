## 0-bis. 比較している手法 — 整理

### 表 0-1. 7 手法の定義と出所

| 記号 | 名称 | 距離の作り方 | 出所 | 何が見えるか |
|---|---|---|---|---|
| **W₁** | Wasserstein-1 | **対距離**。2 標本の分位点差の積分 ∫\|F₁⁻¹−F₂⁻¹\| | **本論文の提案** | 分布全体。**EM の原単位を保持** |
| **KS** | Kolmogorov–Smirnov | **対距離**。sup\|F₁−F₂\| | 既存（標準的な EDF 統計量） | 分布全体。ただし [0,1] に**無次元化**され、汚染割合で**飽和** |
| **SMD** | 標準化平均差 | **対距離**。\|x̄₁−x̄₂\|/s_pooled | 既存（規制実務の慣行） | **位置のみ** |
| **SMD(log)** | 対数尺度 SMD | 同上、log 変換後 | 既存（Set 2 のみ） | 対数尺度での位置のみ |
| **RV1** | 代表値距離 | **座標型**。各国 = 1 点（代表値 1 個）、roster 全体で N(0,1) 標準化 → Euclid | **小宮山 Ch.4 as written** | **位置のみ**（単一連続 EM では代表値 = 平均） |
| **RV2** | RV + SD | **座標型**。各国 = (mean, SD) | **我々の拡張。Ch.4 の提案ではない** | 位置 + ばらつき |
| **RV3** | RV + SD + skew | **座標型**。各国 = (mean, SD, skew) | **我々の拡張。Ch.4 の提案ではない** | 位置 + ばらつき + 非対称性 |

### 構造上の 2 系統

手法は**距離の作り方**で 2 つに分かれ、この違いが盲点の在り処を決める。

- **対距離型（W₁ / KS / SMD）** — 2 国の標本から直接距離を計算する。分布の情報を要約せずに使う
- **座標型（RV1 / RV2 / RV3）** — 各国をまず低次元空間の 1 点に潰し、その後 Euclid 距離を取る。**潰した時点で落ちた情報は永久に戻らない**

→ Set 3（12 国すべてで mean と SD が一致）で RV1・RV2 の座標が**全国同一**になり、母集団距離が厳密に 0 になるのはこの構造の帰結。

### RV1 と SMD が一致する理由（重要）

単一の連続 EM に適用すると、Ch.4 の「1 EM = 1 代表値」は代表値 = **平均**になる。したがって RV1 の距離は標準化された平均差であり、**SMD と同じもの**を測っている。実測でも一致する（ARI 0.489/0.343/−0.000/0.026 対 SMD 0.452/0.334/−0.000/0.018）。

⚠️ **これは Ch.4 への批判ではなく適用範囲の指摘。** Ch.4 の worked example は「男性の割合」「若年患者の割合」——**2 値変数の割合**で、そこでは 1 代表値が分布を完全に記述する。連続 EM に持ち込むと記述が不完全になる、という話。

### 帰属の禁則（`EXISTING_METHODS_AND_NOVELTY.md` §3）

| ❌ 書いてはいけない | ✅ 正しい |
|---|---|
| 「小宮山は (mean, SD) 座標を使う」 | Ch.4 は 1 EM に代表値 **1 個**を与える |
| 「小宮山は skew を座標に足せる」 | Ch.4 は EM の域内分布のモーメントを一切論じない |
| RV2 / RV3 を「小宮山の手法」と呼ぶ | **我々の拡張**。査読者の当然の反論を先回りして自前で用意したもの |
| 「定量的な pooling 手法は存在しない」 | Ch.4 は完全で具体的なレシピを提供している |
| 「小宮山は EM の関連度を無視」 | Lasso 重みづけで扱っている——**我々より進んでいる**（我々に EM 選択法は無い） |
| 「小宮山は pool 数を論じない」 | §4.6.1.3 が答えている（≤ 4、多重性根拠つき）。**我々は論じていない** |

### 公平性の担保（steelman）

Part 1B では **W₁ だけが臨床要件から閾値を導出**する（τ = τ_clin = Δ_clin/L）。競合には**各シナリオ・各 n で距離グリッド全体を探索した oracle-best 閾値**（violation ≤ α の下で sensitivity 最大）を与えている。**競合は答えを教えられ、W₁ は教えられていない。** それでも W₁ が勝つなら、勝ちは閾値選択の産物ではない。

## 1. 中心的な発見 — 手法は 3 つの挙動に分かれる

n を 2000 まで伸ばして初めて区別がついた。**この 3 分類が結果全体の背骨。**

| 挙動 | 定義 | 意味 | 該当 |
|---|---|---|---|
| **Blind（盲目）** | n=2000 まで chance 上で平坦 | 母集団距離に情報が無い。**n=∞ でも解けない** | Set 3 の RV1・RV2・SMD、Set 4 の RV1・SMD |
| **Partial（部分識別）** | chance 超で平坦、閾値未満 | 構造の一部だけ解像し、残りは永久に解けない | Set 1 の RV1(0.50)・SMD(0.46)・RV3(0.74)、Set 4 の RV2(0.38)・RV3(0.25) |
| **Recovering（回復）** | 単調上昇し閾値を越える | 識別はできる。**必要例数の問題** | 全 world の W₁、全 world の KS |

⚠️ **KS はどの world でも blind ではない。** 以前「Set 4 で KS は盲目」と述べる計画だったが、n=2000 で ARI 0.985 まで回復する。**盲目ではなく非力**。

### 表 4-1. Set 4 の真値（sim 自身の出力から検証済み）

| 国 | 役割 | 真の W₁ | 真の KS |
|---|---|---|---|
| T1 | sym_severity | 3.000 | 0.047 |
| T2 | sym_severity | **6.000** | 0.050 |
| P2 | asym_severity | 3.000 | 0.050 |
| S1 | bulk_shift | **2.000** | **0.072** |

**順位逆転**: 最も軽い S1（W₁=2.0）が最悪の T2（W₁=6.0）より KS 上で discordant。

**帰結**: τ ∈ (3, 6) について、ACCEPTABLE = {真の W₁ ≤ τ} を復元する KS 閾値は**存在しない**。T1 を admit する cut は T2 も admit し（KS 差 6%）、S1 を reject するには両方を admit する cut が必要。**これは真値だけの言明で、n=∞ でも成立する。**

## 5. 主張できること（強度順）

### ★★★ 強い — 真値だけ / 漸近で確定

1. **代表値法は matched-moment world で構造的に盲目。** Set 3 で RV1・RV2・SMD の ARI は n=2000 まで chance 上（0.001 / 0.014 / 0.001）。構成上 12 国の (mean, SD) が一致し母集団距離が厳密に 0 だから、**n=∞ でも解けない**。これは power の問題ではなく identification の問題。

2. **RV1（＝小宮山 Ch.4 as written）は SMD と同じ盲点を持つ。** 単一連続 EM では 1 EM = 1 代表値が位置情報しか運ばない。ARI 0.489/0.343/−0.000/0.026 vs SMD 0.452/0.334/−0.000/0.018 — ほぼ一致。**これが citation-faithful な所見**（RV2/RV3 は我々の拡張であり Ch.4 の提案ではない）。

3. **KS は Kantorovich–Rubinstein 型の上界を持たない。** Δ_max = L·W₁ は W₁ 固有。KS にも SMD にも RV にも類似物は無い（W₂ にも無い）。

4. **KS 閾値は臨床要件 {W₁ ≤ τ} を識別できない。** Set 4 の真値で順位逆転（表 4-1）。**任意の n、oracle 調整済み閾値でも不可能。**

5. **モーメントを足すのは無料ではない。** Set 1 で RV3 は RV2 より**悪い**（ARI 0.620 vs 0.996、AUC 0.847 vs 0.988）——不要な第3座標が推定ノイズを注入する。かつ盲目性の保険にもならない（Set 3 shape_sym で RV3 は chance の 0.452）。

### ★★ 中 — 達成可能な n での言明

6. **推奨サイズ n=100 において、両方の難しい world で使えるクラスタリングを出すのは W₁ だけ。** Set 3: W₁ 0.526 / KS 0.503（他は全て ≤0.13）。Set 4: W₁ 0.355 / KS 0.003（RV2 0.271）。両方で 0.2 を超えるのは W₁ のみ。

7. **W₁ は 4 world 中 3 つで最小の必要例数。** Set 3: 364 vs KS 629。Set 4: 376 vs KS 1240（**3.3倍**）。Set 1: 41 vs 49。

8. **KS が誤るとき、より高価な方向に誤る。** Set 4 で false-pooling 比 1.35× に対し harm 比 **2.14×**。臨床的に読めば、KS が選ぶ pool は W₁ が選ぶ pool の**約 2 倍の最悪ケース地域間治療効果差**を許容する。

9. **必要例数はタスクと world で 1 桁違う。** clustering の task floor は 36（Gaussian）〜376（Extremes）。**「n≥100 で十分」は easy world だけの話。**

### ★ 補助 — 設計指針

10. **ρ = W₁/(KS·σ_EM) ヒューリスティック。** ρ/ρ_trans ≲ 1 → KS が並ぶか勝つ、≳ 1.7 → W₁ が勝つ。全セルを retrodict する。

## 6. 主張できないこと / 訂正が必要なもの

| 旧案 | 判定 | 訂正後 |
|---|---|---|
| 「Set 4 が KS を殺す。**盲目**であって underpowered ではない」 | ❌ **誤り** | KS は n=2000 で ARI 0.985 まで回復。**盲目ではなく非力**（必要例数 3.3 倍） |
| 「Set 3 が moment 法を殺し、Set 4 が KS を殺し、W₁ だけが両方生き残る」 | ⚠️ **半分誤り** | 前半は正しく、むしろ強化された。後半は「n=100 では正しいが漸近では成立しない」 |
| RV2 の Set 4 頭打ち（0.378）を「盲目」と呼ぶ | ❌ | **partial**。chance の 4 倍近く、実構造を解像している |
| RV3 の Set 1 頭打ち（0.736）を「盲目」と呼ぶ | ❌ | **partial** |
| 「W₁ は KS より根本的に優れる」（clustering 根拠で） | ❌ | clustering では**効率の差**。根本的優位の根拠は KR bound と順位逆転（★★★ 3・4）に置く |
| bootstrap 上限選択則 | — | **論文外**（Tak 判断）。小 n では棄権になるのは当然 |

**Jessica の要点**: KS への本当の武器は clustering の結果**ではない**。KR bound（★★★ 3）と順位逆転（★★★ 4）——**どちらも n に依存しない**。そちらを前面に出せば「例数を 1240 くれれば KS でいい」という反論は効かない。
