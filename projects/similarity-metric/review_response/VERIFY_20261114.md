## 5. Mathematics re-derived (Appendix A.1–A.2, Proposition 1, closed forms)

1. **Proposition 1.** τ̄₁ − τ̄₂ = ∫τ d(F₁ − F₂) = L∫(τ/L) d(F₁ − F₂); τ/L is 1-Lipschitz, so by KR (eq. dual) |·| ≤ L·W₁. Requires finite first moments (W₁ finite; τ integrable since |τ(x)| ≤ |τ(x₀)| + L|x − x₀|). Correct.
2. **Integration by parts identity** (used for τ*, monotone and KS cases): for Lipschitz τ and F₁, F₂ with finite first moments, E₁τ − E₂τ = ∫ τ′(t)(F₂(t) − F₁(t)) dt (boundary terms t·(F₁−F₂) → 0 by finite means). Checked by writing Eτ(X) = τ(x₀) + ∫_{x₀}^∞ τ′(1−F) − ∫_{−∞}^{x₀} τ′F.
3. **Attainment τ\*** = L∫_{x₀}^x sgn(F₂ − F₁): τ*′ = L·sgn(F₂ − F₁), so the identity gives L∫|F₂ − F₁| = L·W₁. Slope changes sign at every crossing. Correct.
4. **Monotone bound** (0 ≤ τ′ ≤ L): τ̄₁ − τ̄₂ = ∫(F₂ − F₁)τ′ ∈ [−L·A₋, L·A₊], A± = ∫(F₂−F₁)±; A₊ + A₋ = W₁, A₊ − A₋ = ∫(F₂ − F₁) = μ₁ − μ₂. sup|·| = L·max(A₊, A₋) = ½L(W₁ + |μ₁ − μ₂|), attained by τ′ = L·1{F₂ > F₁} (or 1{F₁ > F₂}). A decreasing CATE (−L ≤ τ′ ≤ 0) gives the same supremum by symmetry — the appendix states only the increasing case; "monotone" in L199 is therefore correct. Equality with L·W₁ iff one of A± = 0 (no crossing); = L·W₁/2 iff μ₁ = μ₂. Correct.
5. **KS bound** (BV τ, bounded support): |∫(F₂ − F₁) dτ| ≤ sup|F₁ − F₂|·TV(τ); sharp by a step of height TV at the arg-sup (exact for continuous F; for atoms take the left limit). W₁ ≤ (b − a)D_KS and TV(τ) ≤ L(b − a) ⇒ for |τ′| ≡ L, TV = L(b−a) and L·W₁ ≤ TV·D_KS. Neither dominates in general (threshold CATE: TV small, L large). Every valid bound c·D with constant L over the L-Lipschitz class is ≥ sup = L·W₁ (KR). W₁ ≤ W₂ (Jensen). Correct.
