## 3. Declined items: scientific reasons (text for the response letter)

Jessica's instruction (D-20261012-3 §C) sets the tone. We decline these because they belong to a different paper, not because the reviewer is wrong.

**EXT M3: Study 3 with specified CATEs.** A ranking study that fixes the CATE θ decides its winner through the choice of θ, not through any general property of the measures:
- Linear θ: the effect difference is $L|\Delta\mu|$, so the mean difference wins by construction.
- Step θ at $c$: the effect difference is proportional to $|F_1(c)-F_2(c)|$, so a statistic that compares the CDFs at that point wins.
- The extremal $\tau^*$ of the Kantorovich–Rubinstein duality: the effect difference equals $L W_1$, so $W_1$ wins.

The paper's bound is a worst case over the whole Lipschitz class. Its conservativeness under any one θ is therefore large by design and is not a finding. The reviewer's linear-CATE point is nevertheless correct, and it is now in the manuscript (l.262). Under a linear CATE, a scale-only difference gives zero effect difference although $W_1>0$. Under the V-shaped $\tau(x)=L|x-50|$, the same difference produces the full $LW_1$ while SMD = 0. The Lipschitz class contains both CATEs, Proposition 1 covers both, and the SMD covers only the first. The worst-case nature of the bound is stated at l.678, and l.186–191 derive how the bound tightens under monotonicity.

**EXT M5: equivalence-test decision rule.** The proposed rejection event $\widehat W_{1,U}<\Delta_{\text{clin}}/L_{UB}$ is algebraically the same event as "the whole $L^*$ interval lies above $L_{UB}$", which `tab:gusto_lstar_joint` already displays for every pair. The size of such a test cannot be defined without conditioning on the clinical input $L_{\text{clinical}}\le L_{UB}$. That input is a sponsor judgment, which the paper describes but does not prescribe. Calling the event a test with a type I error would present a property of the sponsor's input as a property of the method. The operating characteristic that does belong to the method is how often the upper limit falls below the true distance. It is now reported as the one-sided upper-limit coverage (l.438, `tab:study2_intervals`). The equivalence framing is stocked as `IDEAS_BACKLOG.md` I-20261012-5. The permutation null and the multiplicity statement (M5b, M5c) are adopted.

**EXT M7(b): standardized estimate from GUSTO-I outcomes.** The GUSTO-I outcomes estimate the CATE of accelerated t-PA versus streptokinase. They do not estimate the CATE of the hypothetical Drug T whose pooling is being planned. $\int\hat\tau\,d(\hat F_1-\hat F_2)$ would therefore measure how conservative the bound is for a different contrast. The application is set at the planning stage (§4, l.511–518), before the new trial has produced any outcome data, when $\tau$ is unknown. In that situation the available tool is a distance between baseline distributions combined with a clinical slope. Plugging in an outcome-based $\hat\tau$ would answer a post-trial question with data the planning stage does not have. The reviewer's underlying concern, that $L_{UB,\text{age}}$ is large, is answered at l.247. There the bound is compared with the overall GUSTO-I effect and with a sourced prognostic gradient, and $L^*$ is reported for every pair so that any smaller bound can be read against it.

**REF M4: ordering metric for Study 1.** Study 1 is an identification study. It asks whether a measure can tell differing distributions from identical ones at some sample size. The paper now says so and draws no claim about ordering from it (l.262, l.563). An ordering metric among discordant candidates needs a reference order, and both candidate references fail:
- If the reference order is true $W_1$, $W_1$ is scored against itself while KS and SMD are scored against a foreign criterion, so the definition of the truth decides the comparison.
- If the reference order is the true effect difference, it depends on the chosen CATE, which is the EXT M3 problem.

For $W_1$ alone, how accurately $\widehat W_1$ orders partners depends on its bias and sampling variability relative to the gaps between partners, and Study 2 characterizes these. The application reports the answer for its own data directly, through patient-level bootstrap rank intervals (`tab:gusto_nabcd`, l.570, l.586).
